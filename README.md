# contlang

**min-co** — минимальный непрерывный конструируемый язык (*minimal + continuous*). Слово = **корень + суффикс части речи (как в эсперанто) + несколько универсальных непрерывных признаков**; связь слов — частицы из Toki Pona. Схема подбирается экспериментами на данных (эмбеддинги, WordNet), см. `data/` и `scripts/`.
