Слова — случайная выборка из `wordlist_en_sense.tsv` (36 сущ., 36 глаголов, 28 прил.), у каждого форма: множественное число, прошедшее, `-ing`, сравнительная степень, наречие или основа. Кодировали два агента (спецификация с 45 корнями, включая MEASURE), декодировали два других; оценка автоматическая (+ мой разбор промахов).

Форма почти не ломается: прошедшее 25 из 28, `-ing` 18 из 18, множественное 19 из 20, сравнительная 6 из 6, наречие 10 из 10. Слабое место — выбор слова: точное попадание 36%, а с близкими синонимами (*alert → watchful*, *indefinite → vague*, *range → extent*, *needs → desires*, *summon → call*) около 55–60% (оценка на глаз).

Типичные промахи: конкретные предметы без корня (*whip → hammer*, *sheet → feather*, *snake → animal*, *iodine → rock*), слова с узким смыслом (*texture, holder, display, direction*), омонимичные формы (*sound, lock, fashion*). Всё это те же признанные потери «грубого» словаря.

## Перепрогон: русский смысл в подсказке + правило латинских названий

Не угадано ни одним декодером: 45 (было 53). Правило латинских названий сработало: `"Serpentes"` → *snakes / serpents*, `"iodine"` → *iodine*, `"Ireland"` + `SAY` → *Irish*. Остаток в основном близкие синонимы (*diminish → shrink*, *indefinite → vague*, *abroad → foreign*, *trails → paths*, *cruder → ruder / harsher*, *fashion → sculpt / create*), на глаз итог около 65–70% с синонимами. Настоящие провалы: *lost → receded / rejected*, *year → duration*, *sound → news*, *needs → dreams*, *summarize → whisper*, *afraid → disgusted*, *sheet → pebble*, *fairer → better*, *narrow → minor*.
