# Слепой тест: оси лица, одушевлённости, MOVE, FEEL; корни RULE, FIGHT

46 слов, кодировал ассистент, декодировали два субагента (sonnet) по спецификации без оригиналов. Слова подбирались под новые оси, оценка завышена.

Итого: слово или синоним 31 из 46 (67%), «рядом» 11, «мимо» 1 (*tax* → permission).

- Местоимения (I, you, we, myself, everyone, nobody, they): 7 из 8 точно, *he* лишь запасным вариантом.
- THING: камень, насекомое, животное, слон верно; *flower, grass, fish* — рядом; *tree* — запасным.
- MOVE: stand, walk, run, crawl, slowly, quickly, sprint верно; *stroll* запасным.
- FEEL: calm, excited, joyful, depressed, relaxed верно; *angry* ↔ *afraid* путаются, *sad* запасным.
- RULE/FIGHT: law, rule, regulation, war, fight, argue, soldier, peace верно; *tax, duty, politics, defend* слабо.
