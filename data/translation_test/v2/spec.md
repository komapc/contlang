# Схема min-co для теста перевода (то, что видит декодер)

Слово = `КОРЕНЬ-суффикс` или `КОРЕНЬ-суффикс(=значение)`. Суффиксы: `-o` имя/предмет, `-i` глагол, `-a` признак, `-e` обстоятельство/образ действия.
Корни: SOMEONE, THING, PEOPLE, BODY, KIND, PART, WORD, SAY, DO, HAPPEN, MOVE, THINK, KNOW, WANT, FEEL, SEE, HEAR, TOUCH, PLACE, INSIDE, SIDE.
Градиентные корни (одна ось от -5 до +5, `(=0)` или без скобок = середина):
- GOOD: +5 очень хорошо ... -5 очень плохо
- BIG: +5 огромный ... -5 крошечный
- NEAR: +5 вплотную ... -5 очень далеко
- ABOVE: +5 высоко над ... -5 глубоко под
- LIVE: +5 полностью жив ... -5 мёртв
- SAME: +5 тот же ... 0 похожий ... -5 противоположный
- MAYBE: 0 простое утверждение, +5 точно истинно, -5 точно ложно, -1 может быть
- ALL: +5 все ... 0 некоторые ... -5 никто/ничего
- TIME (как корень): -5 давно в прошлом ... 0 сейчас ... +5 далеко в будущем
Частицы: LI (сказуемое), E (прямое дополнение), PI (группировка определения), LA (условие / «что» / контекст).
Предварительные частицы: MI (я), SINA (ты); `QUESTION` — вопрос (не определён).
Признаки глагола в скобках с именем: `(TIME=v)` время, от -5 очень давно до +5 когда-нибудь, 0 или пропуск = сейчас/вообще; `(MAYBE=v)` уверенность в утверждении, 0 или пропуск = простое утверждение, +4 наверняка, -1 может быть нет, -2 вряд ли, -5 точно нет (отрицание). `(=v)` без имени — локальная ось самого корня (градиент).
Числа — цифрами; названия собственные в кавычках как есть; даты — номерами (месяц=3, день=5); цвета — `RGB(r,g,b)`.
Универсальные оси (интенсивность и т.п.) в этом тесте не используются.
Пробел между словами; несколько слов подряд без частиц — определение к последнему/первому слову по контексту (дублирует PI).
