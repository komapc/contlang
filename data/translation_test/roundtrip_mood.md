# Настроение: ось MOOD (комедия … трагедия), слепой тест

Предложение автора: ось «смешное … весёлое … нейтральное … грустное … трагедия». На векторах (Numberbatch) она почти совпадает с осью радость—горе (cos 0,76), а ось смешное—серьёзное от неё почти независима (cos 0,15); на нынешние корни не похожа сильнее cos 0,40 (LIVE), с GOOD — 0,31. Своих слов среди 10 ближайших у математики: 3 из 7 → 7 из 7 (comedy 7→1, laugh 15→1, smile 27→3, celebrate 71→3).

Шкала, которую видели кодировщики и декодеры B (`addendum`):

| −5 | −3 | 0 | +3 | +5 |
|---|---|---|---|---|
| горе, отчаяние, трагическое | грусть, печаль | спокойно, всерьёз, без шуток | весело, радостно | смешно, хохот, комическое |

Ноль — «всерьёз», а не «грустно»; катастрофа как событие — `HAPPEN GOOD(=-5)`, не настроение. Примеры только три: комедия `ART MOOD(=+5) | o`, трагедия `ART MOOD(=-5) | o`, смеяться `MOOD(=+5) | i`. **Рецептов для тестовых слов не было** — проверяется, продуктивна ли сама ось (в прошлых тестах B видели рецепты).

Протокол как в [roundtrip_quotes_health](roundtrip_quotes_health.md): A — нынешняя спецификация, B — с корнем MOOD; sonnet, 2 кодировщика, по 1 декодеру на каждого; ✓ лучшее слово, ~ среди трёх (с ближайшими синонимами: sad/unhappy, cry/weep, mourn/grieve…). 16 слов.

| | A1 | A2 | B1 | B2 |
| :-- | --: | --: | --: | --: |
| ✓ первым | 5 | 6 | 12 | 12 |
| ✓ или ~ | 6 | 8 | 15 | 14 |
| одинаковых кодов у двух кодировщиков | 4 из 16 | | 11 из 16 | |

Итого: A — 11 из 32 первым (14 из 32 среди трёх), B — 24 из 32 (29 из 32).

| слово | A1 | A2 | B1 | B2 | код B1 |
| :-- | :-: | :-: | :-: | :-: | :-- |
| happy | ✓ | ✓ | ~ cheerful | ~ cheerful | `MOOD(=+3) \| a` |
| sad | ✓ | ~ upset | ✓ | ✓ | `MOOD(=-3) \| a` |
| funny | ✗ pleasant | ✗ grateful | ✓ | ✓ | `MOOD(=+5) \| a` |
| joke | ✗ compliment | ✓ | ✓ | ✓ | `SAY MOOD(=+5) \| o` |
| cry | ✗ vomit | ~ complain | ✓ | ✓ | `MOOD(=-3) CONSUME(=-5) GRAIN(=-3) \| i` |
| smile | ✗ caress | ✗ relax | ✓ | ✓ | `MOOD(=+3) BODY \| i` |
| grief | ✓ | ✗ horror | ✓ | ✓ | `MOOD(=-5) \| o` |
| cheerful | ✗ friendly | ✗ friendly | ✗ joyful | ✗ delighted | `MOOD(=+3) FEEL(=+3) \| a` |
| celebrate | ✗ enjoy | ✗ dance | ✓ | ✓ | `DO MOOD(=+3) PART(=+5) \| i` |
| party | ✗ happiness | ✗ joy | ✓ | ✓ | `MOOD(=+3) PART(=+5) \| o` |
| funeral | ✗ disaster | ✓ | ✓ | ✗ mourner | `MOOD(=-5) LIVE(=-5) PART(=+5) \| o` |
| depressed | ~ miserable | ✗ sad | ~ gloomy | ~ gloomy | `MOOD(=-4) FEEL(=-4) \| a` |
| humor | ✗ praise | ✗ praise | ~ laughter | ✓ | `MOOD(=+5) \| o` |
| mourn | ✓ | ✓ | ✓ | ✓ | `MOOD(=-5) LIVE(=-5) \| i` |
| serious | ✗ calm | ✓ | ✓ | ✓ | `MOOD(=0) \| a` |
| despair | ✓ | ✓ | ✓ | ✓ | `MOOD(=-5) CAN(=-5) \| o` |

Что видно:

- **Без корня настроение собирают из `FEEL GOOD`**, и всё положительное сливается в «приятное»: смешной → *pleasant*, *grateful*; шутка → *compliment*; юмор → *praise* (оба); улыбка → *caress*, *relax*; весёлый → *friendly*; вечеринка → *happiness*, *joy*. Отрицательный край читается лучше (горе, отчаяние, скорбеть), потому что там есть `LIVE(=-5)` и `CAN(=-5)`.
- **С `MOOD` смешное отделилось от хорошего**: funny, joke, humor, smile, celebrate, party — 11 из 12 первым. Ноль работает как «всерьёз»: `MOOD(=0) | a` — *serious* у обоих.
- **Кодировщики B согласны между собой**: 11 одинаковых кодов из 16 против 4 у A.
- **Слабые места оси**: *happy* и *cheerful* оба получают `MOOD(=+3)` и путаются (декодеры читают *cheerful* и *joyful*); *depressed* читается как *gloomy* (~ у обоих). Нужен рецепт-различитель: счастливый — `MOOD(=+3) GOOD(=+4)`? весёлый — `MOOD(=+4)`? — не проверено. Похороны с `DO` (B2) прочитаны как *mourner* — `DO` делает из события деятеля.
