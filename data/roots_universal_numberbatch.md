# Корни + универсальные оси (numberbatch, 3000 слов, частотность вычтена)

Код слова: корень (log2 R бит) + 3 оси формы + u универсальных смысловых осей + 0/1 локальная ось на корень. Универсальные оси найдены по отклонениям слов от центра своего корня (пулом по всем корням), поэтому значат одно и то же для любого корня. `mask a` — корень использует только a наиболее активных универсальных осей (остальные не кодируются). Сравнение с глобальными осями при той же длине кода в битах.
