# Заранее (2026-11-08, до кодов): связки между частями предложения

Основание — разбор ошибок 240 прочтений текущей грамматики (closed OLD + pipe holdout E1V, классификатор Sonnet):
ошибка строения предложения (C: подчинение, условие/уступка/сравнение, слияние мыслей) — в 150 из 240, в среднем −0,56 балла;
отрицание/количество 37, роли 34, отношения-предлоги 30, местоимения 5, владелец 3. Closed чинил P/O/L — то, что почти не болит.
Типичные ошибки C: *even though* → «if» (у `LA` одна форма на if/when/although), *but* → «;»/«and», *as* → «if», *or* → «;»,
придаточное *who…* → отдельное предложение.

**Изменение** (`grammar.py`, +385 знаков): `LA [ ]` — только время (when, while, as, after, before); новые частицы `IF [ ]` (условие),
`THOUGH [ ]` (уступка); между частями вместо `;` — `BUT`, `BECAUSE`, `SO`, `OR`; `[ ]` сразу после имени описывает это имя
(who, which), имя внутри не повторяется. Это сознательный отход от «всё из корней» — но частицы (AND, LA, FOR, FROM, LIKE) и сейчас
английские слова; корней не добавляется. Решение о принятии — за пользователем.

**Предложения** (`pick.py`): новые 60 из Brown, фильтры pipe, seed 20261109, без предложений pipe и closed, по 6 из 10 жанров;
37 из 60 содержат связку. Оговорка: фильтр ограничивает запятые (≤ 2), сложные предложения недопредставлены.

**Ячейки** OLD и NEW — одинаковы, кроме спецификации; в каждой **2 независимых прогона** кодировщика E0V (a, b: E0 Sonnet →
слепое пословное чтение Haiku → правка Sonnet; один раунд исправления нарушений правил, `check_sent.mjs`, в NEW разрешены новые
частицы), по 2 слепых Haiku (D0) на прогон; судьи Sonnet 0–3, все 480 пар перемешаны. Читателям и судьям запрещено советоваться.

**Главный критерий**: NEW − OLD по оценке /3 (среднее 4 читателей), бутстрап по предложениям (5000, seed 0), нижняя граница 95 % > 0 →
предложить пользователю. Иначе отвергнуто.

**Прогноз**: выигрыш в предложениях со связкой, ≈ 0 без неё; число слов в ячейках примерно равно (связки заменяют `;`,
слов не добавляют) — если NEW раздувается, как closed, это та же неудача. Для сведения: разброс между прогонами a/b;
доля связок того же класса в прочтениях (but/although, if, because, so, or, when/while/as/after/before, who/which);
число новых частиц.
