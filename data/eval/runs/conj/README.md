# conj: связки между частями предложения — результат (2026-11-08)

Заранее: [dec.md](dec.md). Основание — разбор ошибок 240 прочтений текущей грамматики ([taxonomy/](taxonomy/), классификатор Sonnet):

| тип ошибки | прочтений из 240 |
|---|---|
| знаменательное слово (W) | 238 |
| строение предложения (C) | 150 |
| отрицание / количество (N) | 37 |
| роли «кто кого» (R) | 34 |
| отношения-предлоги (L) | 30 |
| время / модальность (T) | 13 |
| местоимения (P) / владелец (O) | 5 / 3 |

Closed чинил P, O, L — то, что почти не болит. Здесь — C: новые частицы `IF`, `THOUGH`, `BUT`, `BECAUSE`, `SO`, `OR`,
`LA` только для времени, `[ ]` после имени — придаточное к нему (патч +385 знаков).
60 новых предложений, 2 независимых прогона кодировщика E0V на ячейку, 8 слепых Haiku, 4 судьи Sonnet. Итоги — [result.txt](result.txt).

| | OLD | NEW |
|---|---|---|
| среднее /3 (прогоны a / b) | 1,22 (1,21 / 1,23) | 1,21 (1,22 / 1,20) |
| связка того же класса в прочтении | 32/124 | **74/124** |
| слов (2 прогона) | 658 | 682 (связок 35) |

**Главный критерий не выполнен**: NEW − OLD −0,01 [−0,14 … +0,12]. Со связкой −0,15 [−0,34 … +0,04], без связки +0,12 [−0,05 … +0,29]
(обе — н. з.; прогноз «выигрыш со связкой» не сбылся).

Что это значит:
- Частицы работают **локально**: класс связки прочитан верно в 60 % против 26 %; код не раздулся (+4 %), кодировщики стабильны
  (разброс прогонов ±0,02 — значит, и в closed проигрыш вряд ли был шумом кодировщика).
- Но **оценка смысла не сдвинулась**: в 238 из 240 прочтений неверно хотя бы одно знаменательное слово, и пока слова не те,
  судье всё равно, «но» между ними или «если». То же в closed: местоимения 36/40 против 28/40 — без выигрыша в смысле.
- Вывод по грамматике: грамматика не узкое место. Её починки видны в своих метриках, но не в смысле предложения;
  потолок задают знаменательные слова.

Решение за пользователем: связки ничего не стоят (−0,01, длина +4 %) и делают структуру читаемой — их можно принять
ради ясности, не ради точности.

Оговорки: n = 60; фильтр ограничивает запятые (≤ 2), сложных предложений мало; классификатор ошибок — одна модель, без проверки.
