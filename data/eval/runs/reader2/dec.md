# Заранее (2026-10-15, до листов): кодер, выбирающий код моделью читателя

Находка без читателей (`pairs_check.py`, `exp.py`): из двух кодов одного слова с разными оценками судьи cos математики выбирает
лучше прочитанный лишь в 32 % пар (обратный знак), модель читателя (../three2/proxy.py) — в 57 %, с признаком «голова × корень» — в 62 %
(в парах кодов математики — 59 %). «Буквальный читатель» по словам спецификации — 42 %.

Тест: 150 новых слов (случайные из словаря сайта, ранг 300–6000, ни одно и ни одна их база не читались раньше; `test_words.json`).
- **M** — нынешний код сайта (база + метки, один смысл).
- **P20** — тот же кодер, но код выбирается моделью читателя v2 (`choose.py`, обучена на всех 4787 прошлых прочтениях) из 20 лучших по cos кодов (`cand.js`, topr 12) и кода сайта.
- **P80** — то же из 80.
Слово в трёх вариантах — у трёх разных читателей, вариант на лист один; слепые Haiku с DEC_SPEC, судья Haiku 2/1/0.

Мера — доля первых ответов «близко» (2), бутстрап по словам.
**Успех: P20 − M или P80 − M с нижней границей 95 % > 0** (две проверки — для решения нужна граница > 0 у той, что выше по точке,
и не хуже другой). Для сведения: P80 − P20 (вред подгонки под модель), по частям речи, «рядом».
Решение о сайте — за пользователем.
