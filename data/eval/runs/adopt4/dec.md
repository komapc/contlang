# Пороги (до ответов)
Два теста LAND, слова свежие (не из ../adopt, ../adopt2, ../adopt3). Судья ../reader, «близко», парный бутстрап по словам.

**Тест 1: кодер сайта** (site/math.js Reader.encode, как на странице «Проба»): словарь сайта против сайт + LAND (../adopt3/dict45).
1200 случайных слов пула; читаются все, чей код изменился (2 слепых читателя на код).
- LAND работает на кодере сайта, если new − old > 0 с нижней границей 95 % > 0; если граница ниже нуля, но разница > 0 —
  «не вредит, не доказано».

**Тест 2: коды модели** (как ../newroots H2): Haiku пишет коды без LAND (spec_old), другая Haiku с spec_land переписывает
только те, где LAND помогает. 208 слов (noun.location / noun.object + 20 случайных), изменено 27 — их читают по 4 слепых читателя.
- Корень полезен языку, если new − old > 0 с нижней границей > 0.
