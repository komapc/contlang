# Две простые идеи для математики (2026-10)

## 1. Корень с осью без значения = «любая степень» — отвергнуто

В рецептах 98 из 236 кодов содержат корень с осью без значения (`SOMEONE`, `MOVE`, `SAY`, `VALUE`…); сейчас чтение ставит 0.
Вариант: оценка слова — максимум по значениям −5…+5 такого корня (`eval.js` → `eval.out`).

| чтение (98 рецептов) | место | первыми | top10 | cos первого прочтения |
|---|--:|--:|--:|--:|
| значение 0 (сейчас) | 37,1 | 7 | 33 | 0,262 |
| любая степень | 41,9 | 5 | 26 | 0,236 |

Хуже: при любом значении к коду подходит слишком много слов. 0 остаётся.

## 2. Самопроверка кодера — работает

Сейчас кодер берёт код с наибольшим cos(код, слово), а не тот, что лучше читается.
Самопроверка (`selfcheck.js` → `selfcheck.out`, `selfcheck.json`): кандидаты — лучшие коды в 1, 2 и 3 корня и их соседи (значение ±1, без одного корня). Кодер читает каждый тем же чтением, что сайт, и берёт код с лучшим местом слова, при равенстве — короче.
«Кратчайший» — только из трёх кодов в 1, 2, 3 корня.

| ① | сейчас: первыми / корней | кратчайший | самопроверка | Δ первыми (95 %) |
|---|--:|--:|--:|--:|
| dev (100) | 69 / 2,97 | 72 / 2,52 | **79 / 2,33** | +10 (+5 … +16) |
| 1000 | 406 / 2,88 | 433 / 2,59 | **487 / 2,48** | +81 (+64 … +98) |
| другие 1000 | 382 / 2,91 | 415 / 2,60 | **502 / 2,52** | +120 (+101 … +141) |

Примеры (другие 1000): *interested* `KNOW(=+2) FEEL(=+2) WANT(=+2)` (место 2) → `KNOW(=+2) FEEL(=+4)` (1); *otherwise* 3 корня (10) → `MANY(=-2) SOMEONE(=-1)` (4).

Оговорки:
- Это улучшение круга самой математики. Понятнее ли такие коды людям и моделям — не проверено (нужен слепой тест).
- Самопроверка иногда убирает головной корень, нужный человеку: *campus* `PLACE NEAR(=+3) ABOVE(=+5)` → `NEAR(=+3) ABOVE(=+5)`. Можно запретить убирать первый корень.
- Кодирование на сайте станет медленнее: около 20 прочтений на слово вместо одного.
