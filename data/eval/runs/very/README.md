# very: как писать «очень» — результат (2026-11-07)

Заранее: [dec.md](dec.md). 12 прилагательных × 4 степени (barely, slightly, very, extremely) + 12 простых слов;
коды прилагательных и наречий степени — Sonnet (`writer.md`), варианты построены правилом (`codes.json`);
8 слепых Haiku (по 2 на вариант), судья Haiku (`judge.md`). Итоги — [result.txt](result.txt).

| вариант | степень точно | смысл «близко» |
|---|---|---|
| I — метка `I` | 99 % | 71 % |
| X — значение оси | 97 % | 73 % |
| IX — оба | 100 % | 70 % |
| W — отдельное слово | 100 % | 71 % |

**Главный критерий не выполнен** (ни один вариант не лучше W на +15 п. п.) → правило для «очень» не нужно,
кодировщик может писать степень любым из способов.

Что это значит и чего не значит:
- Степень — **не узкое место**: все четыре способа читаются почти без ошибок. Узкое место — сам признак (смысл ≈ 71 %:
  *dangerous* → «fragile», *tired* → «dying», *expensive* → «valuable»).
- Тест оказался лёгким (эффект потолка): читателю дана шкала 1–5, а в его списке одно и то же прилагательное встречается со всеми
  степенями — степень легко прочитать по контрасту. Поэтому различия между способами здесь не видны; в одиночном слове или
  в предложении X (значение оси) должен быть слабее: `HEAT(=-4)` без соседей не отличить от просто «холодный».
- Практический вывод для кодировщика: метка `I` — самый короткий и однозначный способ (одно слово, независим от того,
  какой корень несёт признак); в предложениях конвейера `pipe` она и используется (`very → I+4`).
