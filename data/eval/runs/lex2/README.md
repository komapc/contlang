# lex2: проверенный словарь на новых читателях — результат (2026-11-08)

Заранее: [dec.md](dec.md). Те же 120 слов, что в ../lex; 12 новых слепых читателей (на вариант 3 Haiku + 1 Sonnet), 3 судьи Haiku.
Итоги — [result.txt](result.txt).

| вариант | Haiku (3 чтения) | Sonnet (1 чтение) |
|---|---|---|
| V2 — лучший набор lex (контроль) | 73 % | 72 % |
| L — по слову код, лучше всех прочитанный в lex | 76 % | 79 % |
| R — второй круг правки V2 | 73 % | 78 % |

| разница | Haiku | Sonnet |
|---|---|---|
| L − V2, все 120 | +3,1 [−1,1 … +7,8] | +7,5 [+0,8 … +14,2] |
| L − V2, 25 слов, где код другой | **+24,0 [+10,7 … +38,7]** | +20,0 [0 … +40] |
| R − V2, все 120 | −0,3 [−6,7 … +6,1] | +6,7 [−1,7 … +15,0] |

**Критерии 1 и 2 не выполнены** (по всем 120 словам у Haiku ни L, ни R не дают +5 п. п. с интервалом выше нуля).

Что это значит:
- V2 на новых читателях — те же 73 %: уровень lex воспроизводится.
- **Выбор работает там, где он что-то меняет**: на 25 словах, где выбран другой код, +24 п. п. у новых Haiku и +20 у Sonnet.
  По всем 120 эффект размыт, потому что у 95 слов код тот же (это ограничение было записано заранее). Выбор — не подгонка
  под конкретных читателей: он переносится и на новую модель-читателя.
- **Второй круг правки не помогает** (Haiku −0,3): правка по одному чтению даёт выигрыш один раз (lex: +6,5), дальше правщик
  меняет 42 кода, но в среднем не лучше. Значит, рычаг — не «править ещё», а **больше кандидатов + отбор по слепому чтению**.
- Практический путь к словарю частых слов: на слово несколько независимых кодов (разные кодировщики, правка), слепое чтение,
  берётся лучше прочитанный; проверка — на новых читателях. Решение строить такой словарь — за пользователем.

Оговорки: читатели и судьи — модели, в основном Haiku; Sonnet — один читатель на вариант (шумно). L выбран по 2 чтениям lex —
при большем числе чтений выбор был бы точнее.
