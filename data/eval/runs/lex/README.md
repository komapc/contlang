# lex: потолок 45 корней на частых словах — результат (2026-11-08)

Заранее: [dec.md](dec.md); основание — [wordlevel.md](wordlevel.md) (пословный разбор pipe). 120 самых частых слов из ../big1000,
5 наборов кодов, 10 слепых читателей Haiku (по 2 на набор), 3 слепых судьи Haiku. Итоги — [result.txt](result.txt), худшие слова — [worst.md](worst.md).

| вариант | близко | близко или рядом |
|---|---|---|
| H — Haiku, один проход (big1000) | 58 % | 81 % |
| S — Sonnet, один проход (S1 65 %, S2 63 %) | 64 % | 84 % |
| V — S + слепое чтение + правка (V1 69 %, V2 73 %) | **71 %** | 85 % |

V − S +6,5 п. п. [+1,9 … +11,2]; S − H +6,0 [−1,2 … +13,1]; V − H +12,5 [+5,8 … +19,2].

**Критерий 1 не выполнен**: правка по чтению помогает (интервал выше нуля), но меньше заранее заданных +10 п. п.
**Критерий 2: потолок ≥ 70 %** → предел задаёт не набор корней, а кодировщик. У 109 из 120 слов хотя бы один из пяти наборов прочитан
«близко»; во всех наборах «мимо» только *drive* и *character*.

Что это значит:
- 45 корней хватает для ~70 % частых слов вне контекста уже сейчас, и почти любое слово хоть в одном варианте кода читается.
  Довода «нужны новые корни» этот тест не даёт.
- Худшие слова — абстрактные и многозначные (*based, mission, career, status, sector, instead, concerns*): у них нет «физического» ядра,
  кодировщики пишут разное, читатели читают разное. Это тот же провал, что «общее вместо частного» в предложениях.
- Следующий шаг напрашивается сам: **проверенный словарь** — для частого слова брать тот код, который слепые читатели читают верно,
  и проверять его на новых читателях (здесь выбор лучшего из пяти наборов подогнан под этих же читателей, поэтому «109/120» — не оценка).

Оговорки: читатели, правщики-читатели и судьи — одна модель (Haiku); правка подстраивается под неё. В V2 четыре кода после правки
нарушали правила и были исправлены тем же агентом (одна правка, как заранее). Числа и валюта в кавычках (`"2"`, `"dollar"`)
разрешены спецификацией. Толкования WordNet у некоторых слов неудачные (*higher*, *march* как глагол) — одинаково для всех вариантов.
