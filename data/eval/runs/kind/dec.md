species, минус example instance sample specimen case illustration). Кодер сайта с KIND и без (codes.js) на 207 словах, ближайших
к атому, и на 1000 словах ../big1000.

Варианты: old — старый код и прежняя спецификация; new — новый код и спецификация со строкой KIND
(«−5 an example, a sample, an instance, evidence … 0 a model, a pattern … +5 a kind, type, category, class; the plain root means kind, sort»).
Слепые Haiku, по ~45 кодов, у каждого один вариант. Судья 2/1/0, метки ../reader/labels.json.
