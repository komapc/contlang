# «Два слова» 2: основной смысл и выбор кода моделью (2026-10-13)

Продолжение ../twowords. Что изменилось и что проверяли:
- `make1.js` + `make1.py`: 100 случайных существительных из «других 1000» (не имена, не множественное, часть речи o), у которых
  первый смысл-существительное в WordNet — само слово (не gen → information), без informal / slang / abbreviation, без
  «множественных» вроде viewers, findings → words.tsv (слово и толкование первого смысла).
- Пары: два Haiku по `gen/task.md`, теперь с толкованием («describe the noun in that sense») → gen/pairs_K.md.
- `make2.js`: каждому слову (цели и слова пар, 258) — 8 разных кодов математики (лучшие по cos через `Coder.top`;
  каждый следующий делит с каждым уже взятым не больше одного корня; первый = код A) → cands.json, choose/list_K.md.
- Выбор: 7 Haiku по `choose/task.md` (spec + толкование цели) выбирают код, по которому слово угадают вернее → choose/ans_K.md.
  Не первый кандидат выбран у 156 из 258 слов.
- `make3.js` → items.json и списки. A — один код (как сейчас), B — код, выбранный моделью, C — пара кодами математики,
  D — пара кодами, выбранными моделью, E — пара словами. Слепые читатели Haiku: по 2 на вариант и половину (20 запусков),
  A–D по `dec.md`, E по `dec_d.md`. `score.py` → score.txt.

Выводы:
- Выбор моделью помогает: пара с выбранными кодами заметно лучше пары с кодами математики (D / C 0,63, значимо), один код —
  чуть лучше (B / A 0,90, не значимо). Векторам выбранные коды хуже — они читают не так, как люди.
- Но пара кодами по-прежнему не лучше одного кода: среди 8 кандидатов часто нет нужного кода даже для простых слов
  (выборщики сами пишут «no candidate fits»): employee → `RULE(=-1) PART(=+3)`, bowl → `LONG(=+2) HEAT(=-2) CONSUME(=+1)`,
  road (way FOR cars) → `SOMEONE(=0) MANY(=0) MOVE(=+2) | o FOR …`. Узкое место — коды самих слов пары, а не их выбор.
- Пара словами с толкованием читается так же, как без него (5,7 против 5,5) — идея пары по-прежнему сильная.
- Первый смысл WordNet не всегда главный: cake — «брусок мыла», airline — «шланг для воздуха», hybrid — «гибридное слово».
