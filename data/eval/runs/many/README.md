# MANY: двусторонняя шкала (2026-10)

**Было:** односторонняя 0 … +5, «ни одного» = `MANY(=0)`.
**Стало:**

| уровень | смысл |
|---|---|
| −5 | ни одного, нет вовсе |
| −4 | нехватка, отсутствие нужного |
| −3 | почти нет, едва |
| −1 | мало |
| 0 | сколько-то |
| +3 | многие |
| +4 | большинство |
| +5 | все |

## Почему

- Ось у математики строится по полюсам all … none (roots.yaml, semaxis), поэтому уже была двусторонней. Голый `MANY` математика читает так:

  | код | прочтение |
  |---|---|
  | `MANY(=-5)` | absence, zero, lack, nowhere |
  | `MANY(=0)` | certainly, absolutely, definitely |
  | `MANY(=+5)` | kind, whole, entire |

- Кодер ставил отрицательные уровни в 140 из 305 кодов с MANY (5762 слова): lack, absence, insufficient, disappear на −4/−5, hardly, barely, alone на −1/−2. Спецификация этих уровней не знала.

## Проверка

**② Haiku читает коды математики.** 20 кодов с MANY (`codes.json`, `list.md`), по 2 декодера на старой и новой спецификации (`spec_old.md`, `spec_new.md`, `dec_*`), итог — `score.md`:

| спецификация | cos первого ответа | близко |
|---|--:|--:|
| старая | 0,23 | 3 из 40 |
| новая | 0,22 | 1 из 40 |

Разницы нет. Уровни −1/−2 стоят рядом с сильными TONE, CARE, BIG, и декодер MANY почти не замечает. Чтение кодов математики моделью держится на других корнях: см. `../mathread`, `../anchor`.

**③ математика читает коды людей и моделей.** Место слова в прочтении:

| слово | код с `MANY(=0)` | код с `MANY(=-5)` |
|---|--:|--:|
| zero (`MANY(=-5) MEASURE(=-5)`) | 732 | 30 |
| lack (`MANY(=-5)`) | 266 | 7 |
| nowhere (`PLACE MANY(=-5)`) | 33 | 4 |
| peace (`FIGHT MANY(=-5)`) | 1578 | 1598 |
| poor (`VALUE MANY(=-4)`) | 87 | 239 |

Новые уровни лучше совпадают с тем, что математика знает о MANY. Модели пишут «ни одного» как −5 (это естественно для двусторонней шкалы), и математика такие коды понимает.

## Что изменено

- roots.yaml (MANY, `one_sided: false`), сгенерированные таблицы, правило нуля и коррелятивы в lexicon.md («ничто» = `THING MANY(=-5)`).
- Рецепты: peace, poor (−4, нехватка денег), zero, миг и scissors (`MANY(=-1)`, «мало», раньше +1) — encoding.md и data/site/tips_short.md.
- Пример на сайте, тест валидатора, промпты воркера.

Слепой тест с примером «zero» из data/site/examples_words.json остаётся как есть: он записан по старой шкале.
