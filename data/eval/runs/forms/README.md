# Имена в кавычках, множественное с N+3, часть речи из WordNet (2026-10-13)

Слепой тест (../selfcheck_blind) показал: кодер математики кодирует корнями имена (maryland → `PLACE FIGHT(=0) CARE(=-1)`),
формы множественного числа как отдельные слова (dolphins) и пишет `| o` любому слову (smooth, abandon).

`Reader.encode` (site/math.js), списки — scripts/site/build_words.py → words.json:
- `proper` (980 слов): все значения в WordNet — с заглавной → код `"Jakarta"`.
- `plural` (1170): форма множественного числа имени → код леммы (если её нет в словаре — самого слова) с `| o N+3`.
- часть речи — наибольшая доля смыслов по WordNet (`Reader.posOf`); пара через PI — только у имени существительного.

`node eval.js` → eval.out (один код, без пары; имена исключены из обоих вариантов, у них место 1 даром):

| | dev | 1000 без имён | другие 1000 без имён |
|---|--:|--:|--:|
| как было (`| o`, чтение без части речи) | 70/100 | 427/878 | 399/854 |
| часть речи из WordNet | 70/100 | 586/878 | 557/854 |

Имён в случайных выборках 12–15 % (122 и 146 из 1000). Множественных там нет (выборки — леммы); у множественного место то же, что у леммы.
Часть речи даёт +158: чтение со штрафом за чужую часть речи отсекает половину ложных прочтений. У dev часть речи и раньше была задана.

Штраф за неупомянутый корень у главного слова при чтении готового кода (`headAbs`) — хуже для кодов моделей
(cos 0,227 → 0,172, первыми 8 → 5 из 92), рецепты почти так же: модели не называют «самые сильные» корни, выключен.
