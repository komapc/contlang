# Задание декодера

Каждая строка — одно английское слово (существительное, глагол или прилагательное), записанное через более общее слово (главное) и, иногда, второе слово-уточнение. Угадайте закодированное слово. Ответ — строка на пункт, та же нумерация: `N. лучшее | альт1, альт2` (английские слова). Не пропускайте пункты: если не знаете — лучшая догадка.

## Запись
`ГЛАВНОЕ PI(=n) УТОЧНЕНИЕ` — слово является видом (разновидностью) главного, на n ступеней конкретнее по таксономии (n = 1 — прямой вид, n = 3 — вид вида вида). Слово после `PI(=n)` уточняет: оно связано со значением (ассоциация, признак, контекст). Уточнения может не быть: `ГЛАВНОЕ PI(=n)`.
