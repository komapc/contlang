## 1. KIND только головой

Пул: слова рядом с атомом KIND (../kind/kind.json) при v = −5, −3, 0, +3, +5 (по 250, ранг < 20000), все слова ../kind рядом с атомом
и слова ../big1000, у которых в ../kind KIND был головой. Кодер «KIND только головой»: код с KIND, если KIND в нём главный корень,
иначе код без KIND. Слова теста H — те, у кого код с KIND начинается с KIND (побочного сдвига нет по построению).

- old — код без KIND и нынешняя спецификация; new — код с KIND-головой и спецификация со строкой KIND, как в ../kind
  («−5 an example, a sample, an instance, evidence … 0 a model, a pattern … +5 a kind, type, category, class; the plain root means kind, sort»).
- **KIND (только головой) принят в кандидаты**, если new − old на H: нижняя граница 95 % > 0.
- Отдельно (не для решения): 65 слов, где KIND был головой в ../kind (повтор, отбор после чтения), и новые слова.

## 2. SIDE

Пул: 1000 слов ../big1000 и 1500 случайных частых слов (ранг < 10000, не из пула KIND). Слова теста — те, у кого текущий код
содержит SIDE (если их больше 180 — случайные 180).

- **O** — текущий код, нынешняя спецификация (`SIDE: -5 back … +5 front`).
- **R** — код без SIDE (кодер с запретом корня SIDE всем словам), спецификация 44 корней: строки SIDE нет, из рецептов убраны
  восток, запад, северо-восток и leader `SOMEONE SIDE(=+5) RULE`.
- **D** — те же коды, что O; строка SIDE переписана по тому, что атом SIDE значит в векторах (side_kind/atoms.js: −5 back, return,
  recover; +5 ahead, forward, upcoming, prepare): `SIDE: -5 back, behind, backward; also going back, return … +5 front, ahead, forward; also coming up, ready`.

Правила:
- **SIDE можно убрать**, если R − O ≥ −5 % по точке и нижняя граница 95 % > −15 % (правило ../adopt).
- **Новое определение лучше**, если D − O: нижняя граница 95 % > 0.
- Если проходят оба: переопределить, если D − R ≥ 0 по точке, иначе убрать. Если не проходит ничего — SIDE оставить как есть.
- Проверка: у слов без SIDE запрет корня код не меняет (иначе нужен вариант побочного сдвига).
- SIDE стоит примерно в 6 % кодов, поэтому на мере по всему словарю итог — не больше 1–2 %. Удаление касается и рецептов модели
  (стороны света, leader); его проверяет только этот тест кодера сайта, ablation3 (модель) SIDE оставил.
