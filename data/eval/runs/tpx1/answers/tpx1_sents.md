1. oma lun sono ju nowi: pon nin nisa kene jon unu.
2. nowi lun jakan maso ju ili momi kene momi.
3. meju wasun nen oma jeme lun jukon kan nowi lun kan loto tusa oma nisa jakan oma miko.
4. kan pusu pon nen pon pusu ju oma lun panu miko miko.
5. jon situ lun lapan ju jon jakan ju lopomun jakan kene nin niwe.
6. miki oma lun Af loto sono kasu.
7. pon sono ju meju pon jase kan ponu nanu lun pusu ju nin jeme Jessica lun kisa wekin nin topun nisa nanu lun lapan ju mimen jato kene nin oma.
8. oma lun jakan ju miko ke pisu nisa tamose sala miko.
9. nin lun tusa epo kisa ju nowi: kone panu sopa mipi ju oma. meju wasun nen nin lun panu topun mipi.
10. nin maken Mike lun jun ju kipa kan meju nowi: nin nisa jun kipa lun kene nejo kan kima.
11. sopa nisa ili nowi lun nin maka maso, nin Barnaba, nin nisa pusu kun.
12. pon pusu ju kunalin nen, pon pusu ju nowi: moju maso lun panu ake kene ili momi.
13. meju wasun pon panu ake nen pon laka epo ju kepon, pon maka ju kepon.
14. kan ponu wanen nisa pepen nen kun jasan kuma nisa situ sewan lun kan. oma lun miko epo lun jakan pusu.
15. najen jeme oma lun lapan ju wanen kene oma somo oma lun jase nejo.
16. meju nowi nen oma lun totason mipi ju nin suja kuma nisa nanu topun. nin lun jase ju oma mipi. nin Slate lun lulo ju nowi.
17. nin sono maka Fortman lun lulo ju nowi: kene kan mimen lun jakan ju jasan kepon.
18. pon uso kisa ju lulo kene nin maso.
19. ja lun niwe, somo miki momi nisa maje topun lun ja miko maso.
20. nin kasu Jesu lun lulo ju jakan nisa kupo maka. oma lun lapan ju ili wekin kene pon kan situ josun.
21. nowi lun lapan ju tako mipi kene lulo ke kisa nisa tuteto sono.
22. nin topun niwe lun lulo ju nowi: maken nisa pusu epo lun lulo ju nowi kene oma: kone jakan kene nin maka.
23. nasulu momi nowi lun jakan lun mikun jakan. nin lepe maso lun kisa lepe. oma lun wekin.
24. oma lun nasulu nejo kan mose nisa nejo kasu lun kene kupo loto mele.
25. meju niwe nen pon sono ju loto: nowi nen jeme lun jun ju kun nisa mimen kasu.
26. oma lun lapan ju san mimen kan sasa nisa situ josun, kan sasa kun.
27. nin nisa kisa mose kan jon Tawan lun lapan ju tako nowi kene pon: oma lun maken nisa sono kan.
28. oma lun lulo ju nowi kene tuteto nisa kisa oma: kone kisa wekin ili kan.
29. meju nowi nen nin maso nisa jon nowi lun pusu wekin nowi, lun kisa ju nowi.
30. nin weso lun tusa epo ju nowi: nin lun lapan ju musan kene wanen oma. oma lun lapan ju kun sewan kene wanen.
31. meju maso nen, maje mipi lun tusa panu.
32. meju nowi nen pon tako maka epo loto wipon nisa tusan suja, wekin nin nisa meju wasun lun tako maka loto sele sepan.
33. meju nowi nen oma lun sono ju ili nisa totason oma.
34. lulo nisa jakan maso nen, kepon tusa sono ju unu nisa mose sono.
35. somo nin sepan nisa uja lun kan, ke nin nisa jon unu lun tusa maso. nin unu lun pusu lun tako jakan lun jase.
36. nowi lun jakan kene nin nisa tako maka loto wasun nisa jon Hungary.
37. oma lun kene pepen jakan kene nin maken nisa kan sasa jon lun nejo ju lopomun oma kene pusu ju oma.
38. pon sepan nasulu lun lepe nen ili nisa isa lun tokele lun kupo.
39. moju kasu nisa kokon pepen lun ja kisa sopa epo pusu kene mele nisa jasan kun, kan nani.
40. kan kisa nisa maje nen oma lun epo ponu somo lun ake.
41. nin Norton ke nin Rochford lun totason sepan kene nasulu nisa wipon suja.
42. maka nisa lopomun ke sala epo lun kan ake oma. oma lun tako maka loto nin niwe lun maka, ke loto nin topun lun tusa maso.
43. sepan nisa nin nowi lun uso loto tako nisa kisa epo, oma lun totason ju nowi.
44. oma lun tako ju nowi: lulo unu lun tusa epo kene jeme kisa.
45. oma lun kun ju kun nisa nin kisa. jeme lun jato maso lun kun ju kun tejun ke jela.
46. nowi lun loto nowi: ili maso lun kan ke oma lun panu.
47. nanu sala lun jun ju wipon sono mipi nisa maje moju josun. wipon nowi lun kisa ju ili maso.
48. nin nisa maje topun lun lulo ju nowi: nowi lun miko. somo oma lun kupo ju nowi loto maje topun oma.
49. ili lun maka maso nen tuteto nowi lun tusa maso kene ake.
50. nowi lun jun ju ili maso ke ja maka kan topun. oma lun kene kisa weso kepon.
51. ja momi nisa wasun nisa mose pon lun kupo.
52. lulo nen oma lun ja kene suja kan mimen nejo. oma lun suja kene nanu kene nisa totason mimen.
53. oma lun jase nejo kun mimen lun mikun ju mimen miko lun nasulu kan jasan.
54. sasa jukon lun kan epo loto kima je nisa jukon ke kima kun nisa jukon.
55. tamose situ sepan lun panu kasu loto jon nisa munen niwe.
56. nowi nen oma lun jakan ju neku maka nisa nanu lepe.
57. nin weso ke nin maka nisa sala maka lun jun ju lulo.
58. meju nowi nen maka suja lun ja tokele maso ju jeme mipi nisa nanu uja, kan lopomun ke kan tako.
59. meju maso nen nin lun panu kasu loto meju maso ke meju kan sopa sala. oma lun panu kasu loto kisa jakan epo.
60. nin Greg lun kene kasu kan ponu pepen kasu lun topun ju oma kene mose nisa nanu oma.
