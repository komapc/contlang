## p10d
1. nin Linda lun tusa jase, lun sono.
2. somo meju maso niwe lun mano loto meju miko maso wasun?
3. meju maso nen nin lun pusu ju nin tokele John lun totason, jun epo ju lapan sono nisa jeme jakan. maken lun tusa panu kasu.
4. ja nen oma lun kisa ju ili miko.

## p1d
1. jeme lun kisa ju sono ju jopa jato mipi. oma lun pusu ju jopa nowi, lun tako jakan ju oma, lun lapan ju oma kene lepe totason.
2. meju kuma nen oma lun kisa ju jopa loto tusa kunalin pusu, loto nowi: oma lun mikun ju lulo "oma lun nin nisa lepe totason maso niwe".
3. meju kuma sopa nen oma lun kisa kan sasa nisa nanu Beverly Hilton. nowi lun loto nin topun nisa pusu maka ke isa maka.

## p7d
1. wipon pusu nisa sono jakan lun jase kan mose, loto nowi: oma lun wekin mose kan nisa kasu.
2. mose nowi lun ja kisa jakan maso loto mose nisa sono jon.
3. wipon pusu lun kan nen, pon pusu ju pepen nisa wipon sopa, lun kene ju sasa, loto nowi: oma lun wekin.

## p8d
1. meju niwe somo nen pon pusu ju oma, somo oma lun unu, pon lun unu.
2. kan pepen, maken kuma lun tokele, lun kene maka, lun lapan ju mimen jela kan nani.
3. nin nisa nasulu epo, nin nisa nasulu moju epo kan, kun jela lun jun ju san niwe.
4. oma lun kene sotaku wipon totason. kan pepen oma nen totason ke tako maka ke tako tokele lun jase.
5. tuteto kan nani tuteto lun panu kan mose, pepen lun wekin momi, oma lun kene kan mimen nisa san maso.

## p3d
1. nasulu miko moju nowi lun sepan maso, lun ja maso. oma lun panu jakan maso loto mose kisa suja.
2. tako maka kan uso lun tokele ju oma kan meju sopa. kupi oma lun tusan niwe.
3. somo kan meju oma lun nasulu jakan maso nen, oma lun ja nasulu lepe ju nasulu miko nowi, lun jakan maso.

## p4d
1. ponu nani nisa wipon kene lun kan linili nisa mele wasun.
2. linili nowi lun ja kene niwe kin, somo lun kene ponu wekin mose unu.
3. miki nisa linili wasun lun loto nowi: ili maka maso lun tusa kupo.

## p6d
1. nowi lun kupo loto jon nisa maje nowi wasun, tusa kisa ju lulo nisa mose topun miko maso.
2. lulo nowi lun niwe loto nowi: mose nisa tusa kisa lun lapan ju tusa panu. nowi lun lapan ju tusa miko maje nowi kene meju panu.
3. pon lapan ju pusu kene tusa kisa. loto nowi nen pon pusu ju sopa nisa tusa kisa wasun, nowi lun sono jakan nisa tusa miko.

## p9d
1. oma lun kene suja sepan loto lopun mipi, lun kisa.
2. oma lun lapan ju tamose kene mele unu, lun kene pepen sotaku suja.
3. kan meju maso nen mele lun panu kasu, lun lapan ju oma kene jon uso.
4. somo oma lun tusa ja.
5. oma lun kupo loto mele niwe, san lun kene nani oma, lun pusu kan momi.

## p5d
1. kan jon Piazza Navona nen nanu pisu jakan maso lun kan. kepon ja jase kan, pisu ju mimen, pisu, pusu ju mimen kasu kan jon miko.
2. ili kan pepen kepon lun lepe maso, lun kan kunalin kene maso nisa jon Roma.
3. ja nen nin nisa nasulu lepe lun kene ponu, lun lapan ju ili mipi.

## p2d
1. nin Hubert Humphrey lun topun nisa tuteto miko. nowi lun kan: oma lun maken jun ju je jakan ju tako jakan.
2. oma lun wekin nin maso: oma lun tusa jase kan, lun tusa sono ju jon kasu, lun tusa tako suja loto jon epo nanu.
3. kone jun ju sasa maso nisa jase kan, ju jon kupo niwe kan ponu nisa mimen kasu ke situ.
4. kone jun ju nanu pisu kan jon epo nanu, wekin nin nisa jon Falanse. nin lun ja jukon jakan, lulo jakan, pusu ju tuteto kene.
