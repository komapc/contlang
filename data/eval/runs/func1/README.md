# func1 — «по назначению» помогает предметам (+14 п. п.), но в целом не доказано (+7,5 [−4,6 … +20])

Заранее: [dec.md](dec.md) (коммит `2741423`, до кодов). Скрипт: [run.py](run.py); итоги и все коды с прочтениями по
словам — [result.txt](result.txt); слова [items.json](items.json), коды [codes.json](codes.json), ответы [answers/](answers/).

## Итог (60 слов, первый ответ читателя, 2 судьи — точное согласие 94 %)

| | A (v1) | B (по назначению, `AGAINST`, до 3 слов) | B − A |
|---|---|---|---|
| **близко** | 36 % | 44 % | **+7,5 п. п. [−4,6 … +20,0]** |
| близко или рядом | 78 % | 78 % | −0,8 |
| близко, предметы (28) | 37 % | 51 % | +14,3 |
| близко, остальное (32) | 36 % | 38 % | +1,6 |

**По правилу из dec.md: интервал включает 0** — само по себе правило не доказано. Прогноз Claude (+10, на предметах
больше, на остальном около 0) по форме сбылся, но 60 слов для такой разницы мало.

- B писал в среднем 1,95 слова на понятие (A — 1,05); `FOR` — 35 раз, `AGAINST` — всего 3 (тюрьма = «место против
  движения для власти-вражды» → *fortress / jail*). Зонтиков в выборке не было.
- Где B выиграл — места и предметы по назначению: *dairy* (место для молока самки), *palace*, *temple*, *kitchen*,
  *restaurant*, *museum*, *prison*, а также части тела через `PI` (*eyebrow* — волос над глазом, часть тела-зрения;
  *wrist*).
- Где B проиграл — почти всё **не из-за правила**: кодировщики A написали *hydrogen*, *helium*, *Pacific* в кавычках
  (спецификация разрешает научные названия веществ), кодировщики B — нет. Без 8 слов, где кавычки есть хотя бы в одном
  коде, B − A ≈ +10 п. п. (подсчёт после прогона, для сведения). Ещё: *chicken*, *meat* — «тело животного для еды»
  читается как «корм», *doll* — фраза длиннее, но расплывчатее.
- Провалы обоих (*artery, fountain, ion, liver, radar, pea, walnut, hut, molecule, sheep, protein, receiver, supper,
  reactor, cafeteria*) — нет опоры: ни назначение, ни форма не отличают от соседа (*radar* ↔ *telescope*, *hut* ↔ *arena*,
  *sheep* = «животное-шерсть» → *wool*).

## Что это значит

1. Называть **места и инструменты по назначению** (`PLACE FOR …`, `… | o tool FOR …`) — стоит; это хорошее правило для
   составления словаря, пусть и не доказанное на 60 словах.
2. `AGAINST` кодировщик почти не берёт сам; полезна ли связка, этот прогон не показал.
3. Около четверти слов не читаются ни так, ни так — это и есть место для **проверенного словаря** (выбор кода слепым
   чтением): правило даёт хороший первый кандидат, словарь закрепляет тот, что реально читается.

## Оговорки

- 60 слов, 2 кодировщика на плечо: разброс кодировщиков сравним с эффектом.
- Слова вне контекста; в предложении фраза из 2–3 слов может мешать разбору (не проверялось).
