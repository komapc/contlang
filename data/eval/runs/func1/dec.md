# Заранее (2026-11-12, до кодов): func1 — называть вещь по назначению, фразой до 3 слов

**Основание.** Зонтик закодирован как `ABOVE(=+5) LONG` («длинное наверху») и прочитан «высокая балка» ([gap1](../gap1/README.md)).
Пользователь: лучше по назначению («анти-дождь»), «можно в 2–3 слова, я не против». В min-co нет связки «против».

**Слова.** 60 конкретных существительных, случайно (seed 20261113) из лемм Brown с рангом 1000–8000, у которых первое значение
WordNet — предмет, вещество, еда, часть тела, животное, растение или природный объект ([items.json](items.json); 28 предметов).
Не из bench1 dev/hold и не по провалам. Кодировщику дано слово и толкование WordNet.

**Плечи** (кодировщик — Sonnet, по 2 на плечо, по 30 слов, задача [tasks/write.md](tasks/write.md)):
- **A** — спецификация mc (v2b2) как есть: одно слово или `X LINK Y` (FROM / FOR / LIKE / PI);
- **B** — та же, но раздел «Two words» заменён на [«Phrases»](tasks/phrases.md): до 3 слов и новая связка **`AGAINST`**
  (защищает от Y, останавливает Y; пример — зонтик), и добавлено [правило «сначала назначение»](tasks/function_rule.md).
  Читатель B получает тот же раздел «Phrases» (без правила для кодировщика).

**Чтение.** По 2 читателя Haiku на плечо, все 60 кодов вперемешку, без контекста: лучший ответ + 2 запасных
([tasks/read.md](tasks/read.md)). Судят 2 судьи Sonnet все 240 первых ответов (0 мимо / 1 рядом / 2 близко, задача lex).
Агентов: 4 + 4 + 2 = 10. Скрипт: [run.py](run.py).

**Меры.** Главная — доля «близко» (2), B − A, бутстреп по словам (5000, seed 0). Для сведения: «близко или рядом»; отдельно
предметы (noun.artifact) и остальные; сколько кодов B используют FOR / AGAINST / tool, средняя длина в словах.

**Решение (заранее):**
- B − A ≥ +10 п. п., интервал выше 0 → правило «по назначению» + `AGAINST` + фразы до 3 слов идут в основу 2.0 и в правила
  составления словаря;
- интервал включает 0 → само по себе правило не помогает; `AGAINST` можно оставить как удобную связку, но словарь строить
  с отбором кодов слепым чтением (lex2), а не правилом;
- B − A ≤ −10 п. п. → фразы мешают (читатель теряется в длинных кодах).

**Прогноз Claude:** A ≈ 45 % «близко», B ≈ 55 % (+10, шанс интервала выше 0 — около 55 %); на предметах выигрыш больше
(+15), на остальных около 0.
