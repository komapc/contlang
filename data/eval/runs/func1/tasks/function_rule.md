
NAMING THINGS: name a thing first by what it is FOR or AGAINST (its use), and only then by its look or material. A tool,
device, garment, building or substance is best named as its kind + its use: `{ THING | o tool } FOR { … }`,
`{ PLACE | o } FOR { … }`, `{ LONG(=-5) | o } AGAINST { … }`. Use a phrase of 2–3 words when one word is not clear.
