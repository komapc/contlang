1. lulo, oma ja kene suja kan mimen nejo. oma suja kene nanu kene totason mimen.
2. nin weso ke nin maka sala maka jun lulo.
3. ili maka maso, tuteto nowi tusa maso kene ake.
4. pon pusu kunalin, pon pusu nowi: moju maso panu ake kene ili momi.
5. oma kun kun nin kisa. jeme jato maso kun kun tejun ke jela.
6. meju nowi, nin maso jon nowi pusu wekin nowi, kisa nowi.
7. oma nasulu nejo kan mose nejo kasu kene kupo loto mele.
8. nowi jakan maso ili momi kene momi.
9. meju wasun, oma jeme jukon kan nowi kan loto tusa oma jakan oma miko.
10. moju kasu kokon pepen ja kisa sopa epo pusu kene mele jasan kun, kan nani.
11. nanu sala jun wipon sono mipi maje moju josun. wipon nowi kisa ili maso.
12. pon uso kisa lulo kene nin maso.
13. nin maje topun lulo nowi: nowi miko. somo oma kupo nowi loto maje topun oma.
14. oma kene pepen jakan kene nin maken kan sasa jon nejo lopomun oma kene pusu oma.
15. nowi jun ili maso ke ja maka kan topun. oma kene kisa weso kepon.
16. pon sepan nasulu lepe, ili isa tokele kupo.
17. tamose situ sepan panu kasu loto jon munen niwe.
18. somo nin sepan uja kan, ke nin jon unu tusa maso. nin unu pusu tako jakan jase.
19. kan ponu wanen pepen, kun jasan kuma situ sewan kan. oma miko epo jakan pusu.
20. nin tusa epo kisa nowi: kone panu sopa mipi oma. meju wasun, nin panu topun mipi.
21. oma jase nejo kun mimen mikun mimen miko nasulu kan jasan.
22. nin maken Mike jun kipa kan meju nowi: nin jun kipa kene nejo kan kima.
23. nin weso tusa epo nowi: nin lapan musan kene wanen oma. oma lapan kun sewan kene wanen.
24. nin Greg kene kasu kan ponu pepen kasu topun oma kene mose nanu oma.
25. pon sono meju pon jase kan ponu nanu pusu nin jeme Jessica kisa wekin nin topun nanu lapan mimen jato kene nin oma.
26. ja niwe, somo miki momi maje topun ja miko maso.
27. meju maso, nin panu kasu loto meju maso ke meju kan sopa sala. oma panu kasu loto kisa jakan epo.
28. nin topun niwe lulo nowi: maken pusu epo lulo nowi kene oma: kone jakan kene nin maka.
29. nowi, oma jakan neku maka nanu lepe.
30. sasa jukon kan epo loto kima je jukon ke kima kun jukon.
31. oma lapan san mimen kan sasa situ josun, kan sasa kun.
32. meju nowi, oma sono ili totason oma.
33. meju nowi, maka suja ja tokele maso jeme mipi nanu uja, kan lopomun ke kan tako.
34. nowi loto nowi: ili maso kan ke oma panu.
35. oma tako nowi: lulo unu tusa epo kene jeme kisa.
36. nin kisa mose kan jon Tawan lapan tako nowi kene pon: oma maken sono kan.
37. miki oma Af loto sono kasu.
38. jon situ lapan jon jakan lopomun jakan kene nin niwe.
39. kan kisa maje, oma epo ponu somo ake.
40. oma sono nowi: pon nin kene jon unu.
41. nowi jakan kene nin tako maka loto wasun jon Hungary.
42. meju wasun pon panu ake, pon laka epo kepon, pon maka kepon.
43. sopa ili nowi nin maka maso, nin Barnaba, nin pusu kun.
44. meju nowi, oma totason mipi nin suja kuma nanu topun. nin jase oma mipi. nin Slate lulo nowi.
45. nin Norton ke nin Rochford totason sepan kene nasulu wipon suja.
46. maka lopomun ke sala epo kan ake oma. oma tako maka loto nin niwe maka, ke loto nin topun tusa maso.
47. lulo jakan maso, kepon tusa sono unu mose sono.
48. meju nowi, pon tako maka epo loto wipon tusan suja, wekin nin meju wasun tako maka loto sele sepan.
49. oma lulo nowi kene tuteto kisa oma: kone kisa wekin ili kan.
50. ja momi wasun mose pon kupo.
51. nowi lapan tako mipi kene lulo ke kisa tuteto sono.
52. nasulu momi nowi jakan mikun jakan. nin lepe maso kisa lepe. oma wekin.
53. kan pusu pon, pon pusu oma panu miko miko.
54. meju niwe, pon sono loto: nowi, jeme jun kun mimen kasu.
55. nin sono maka Fortman lulo nowi: kene kan mimen jakan jasan kepon.
56. nin kasu Jesu lulo jakan kupo maka. oma lapan ili wekin kene pon kan situ josun.
57. oma jakan miko ke pisu tamose sala miko.
58. sepan nin nowi uso loto tako kisa epo, oma totason nowi.
59. meju maso, maje mipi tusa panu.
60. najen jeme oma lapan wanen kene oma somo oma jase nejo.
