2. nin Greg kene kasu kan ponu pepen kasu topun oma kene mose nanu oma.
3. jon situ lapan jon jakan lopomun jakan kene nin niwe.
4. nanu sala jun wipon sono mipi maje moju josun. wipon nowi kisa ili maso.
5. nin topun niwe lulo nowi: maken pusu epo lulo nowi kene oma: kone jakan kene nin maka.
6. somo nin sepan uja kan, ke nin jon unu tusa maso. nin unu pusu tako jakan jase.
7. maka lopomun ke sala epo kan ake oma. oma tako maka loto nin niwe maka, ke loto nin topun tusa maso.
8. pon uso kisa lulo kene nin maso.
9. meju wasun pon panu ake, pon laka epo kepon, pon maka kepon.
10. nowi jakan kene nin tako maka loto wasun jon Hungary.
11. oma tako nowi: lulo unu tusa epo kene jeme kisa.
12. miki oma Af loto sono kasu.

14. ja niwe, somo miki momi maje topun ja miko maso.
15. nowi jakan maso ili momi kene momi.
16. meju nowi, maka suja ja tokele maso jeme mipi nanu uja, kan lopomun ke kan tako.
17. oma kene pepen jakan kene nin maken kan sasa jon nejo lopomun oma kene pusu oma.
18. tamose situ sepan panu kasu loto jon munen niwe.
19. oma sono nowi: pon nin kene jon unu.
20. nowi, oma jakan neku maka nanu lepe.
21. oma lapan san mimen kan sasa situ josun, kan sasa kun.
22. kan kisa maje, oma epo ponu somo ake.
23. meju nowi, oma totason mipi nin suja kuma nanu topun. nin jase oma mipi. nin Slate lulo nowi.
24. lulo, oma ja kene suja kan mimen nejo. oma suja kene nanu kene totason mimen.
25. meju nowi, nin maso jon nowi pusu wekin nowi, kisa nowi.
26. sopa ili nowi nin maka maso, nin Barnaba, nin pusu kun.
27. ja momi wasun mose pon kupo.

31. meju nowi, oma sono ili totason oma.
32. nin maken Mike jun kipa kan meju nowi: nin jun kipa kene nejo kan kima.

35. oma kun kun nin kisa. jeme jato maso kun kun tejun ke jela.
36. meju nowi, pon tako maka epo loto wipon tusan suja, wekin nin meju wasun tako maka loto sele sepan.
37. nin kisa mose kan jon Tawan lapan tako nowi kene pon: oma maken sono kan.

39. nowi jun ili maso ke ja maka kan topun. oma kene kisa weso kepon.
40. nin weso ke nin maka sala maka jun lulo.
41. nin weso tusa epo nowi: nin lapan musan kene wanen oma. oma lapan kun sewan kene wanen.
42. oma jakan miko ke pisu tamose sala miko.
43. meju wasun, oma jeme jukon kan nowi kan loto tusa oma jakan oma miko.
