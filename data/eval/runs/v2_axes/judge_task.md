# Task

`pairs.md` has numbered pairs of English expressions `A: … || B: …`. For each pair, judge whether A and B mean the same thing
or lie in the same narrow semantic field:

- **2** — close: same meaning or the same narrow semantic field (*liquid* / *water*, *slightly warm* / *lukewarm*);
- **1** — related: same broad topic, but a different thing or a clearly different degree (*liquid* / *gas*, *warm* / *boiling*);
- **0** — different.

Write `scores.md`, one line per pair, same numbering: `1. 2`. Score every line. Do not explain.
