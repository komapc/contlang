# Пилот осей — результат (2026-11-10)

Заранее: [dec.md](dec.md). 38 корней × 5 значений (−4, −2, 0, +2, +4) = 190 кодов без контекста; 3 слепых Haiku видят только
полюса осей и общее правило шкалы; 2 судьи Sonnet. Итоги — [result.txt](result.txt), прочтения — [answers/](answers/), оценки — [judge/](judge/).

| тип | корней | согласие читателей |
|---|--:|--:|
| степень | 18 | 91 % |

| лестница | 15 | 84 % |

**Критерий не выполнен**: степень − лестница +7,0 п. п. [−0,5 … +14,5] (порог +15). Прогноз Claude (70 % против 40 %) не сбылся.

Что это значит:
- **Шкала по двум полюсам читается предсказуемо почти у всех корней**, в том числе у «лестниц»: GRAIN — газ, частицы, порошок,
  кусок, твёрдое; FIGHT — игра, состязание, борьба, битва, война; MEASURE — количество, счёт, мера, отношение, процент.
  Читатели сами строят промежуточные ступени, и строят одинаково. Деление «степень / лестница» на глаз не подтвердилось.
- **Но читатели сходятся не на тех ступенях, что записаны в `roots.yaml`**: промежуточные опоры угаданы в 52 % прочтений.
  Мимо: THING 0 «plant» (читают «object»), SAME −4 «special» («opposite»), TIME 0 «now» («time»), MOOD 0 «serious» («mood»),
  INSIDE 0 «border» («inside»), LIVE −2 «asleep» («dying»), PART +2 «the whole» («group»), RULE +4 «authority» («law»),
  GIVE 0 «exchange» («give, offer»).
- **Значение 0 читается как сам корень**, а не как середина между полюсами: `TIME(=0)` — «time», `MOOD(=0)` — «mood»,
  `TOUCH(=0)` — «touch». Согласие ниже всего у 0 и ±2 (82–86 %), у ±4 — 95–99 %.
- Слабее всего согласие у CHANGE и RULE (60 %), затем SOMEONE, GRAIN, LONG, CONSUME, LAND (73 %).

Вывод для 2.0: проблема не в «лестницах», а в **особых опорах**, которые не выводятся из полюсов. Если ось задаётся только
полюсами, а промежуточное значение — тем, что из них следует, шкала работает как степени эсперанто без заучивания ступеней.
Опоры, которые расходятся с этим (список выше), — кандидаты на пересмотр: сдвинуть полюс, сделать опору отдельным корнем
или убрать. Правило для 0 стоит записать явно: «0 — сам корень без сдвига».

Оговорки: все три читателя — одна модель (Haiku), поэтому согласие завышено общими привычками модели; это проверка
предсказуемости, а не понимания человеком. Коды без контекста. Деление на типы — моё, на глаз.

**Уточнение пользователя (2026-11-10)**: ученик знает ось, включая середину и промежуточные опоры: если они логичны,
это калибровка, а не заучивание с нуля, и усилий не требует. Поэтому промах читателя по опоре сам по себе не ошибка оси
(TIME 0 «now», THING 0 «plant», LIVE −2 «asleep», GIVE 0 «exchange» — логичная калибровка). Пересматривать стоит только
нелогичные опоры и расплывчатые оси: SAME −4 «special» (не лежит между «opposite» и «identical»), оси CHANGE и RULE (согласие 60 %).
