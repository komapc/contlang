# Task

You are learning a constructed language. `card.md` lists its roots; each root has an axis, and only the two ends of the axis are given.
`codes.md` has numbered codes `ROOT(=v)`. For each code, write what it most likely means: an English word or a short phrase
(any part of speech). Use only the card; no other knowledge of this language exists.

Write `answers.md`, one line per code, same numbering:

```
1. best reading | second reading
```

Answer every line. Do not explain.
