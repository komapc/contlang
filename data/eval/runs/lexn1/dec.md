# Заранее (2026-11-12, до прочтений): lexn1 — сколько дал бы общий словарь размера N

**Вопрос.** [diag1](../diag1/README.md): подсказка к каждому слову min-co поднимает 1,05 → 2,24. Естественная идея —
**общий словарь** готовых слов с закреплёнными кодами, который знают и кодировщик, и читатель. Но словарь конечен, а
потерянные слова часто редкие: из провалов gap1 *umbrella*, *carpet*, *mud*, *glove*, *comet*, *lenient* стоят на местах
2 500–10 000 по частоте в Brown. Прежде чем строить словарь (это ~20 агентов на 1000 статей), симулируем его размер
подсказками diag1, без новых кодов.

**Плечи** (предложения bench1 dev, 60):
- **mc**, **mcg** (все подсказки), **tpx** — прочтения из v2b2, diag1, tpx1, не перечитываются;
- **g300, g1000, g3000** — те же коды mc; подсказка `<…>` из diag1 оставлена только у слов, чья подсказка целиком (все
  содержательные слова, по худшему рангу) входит в первые N лемм Brown (`ranks.json`, лемма — WordNet morphy, ранг —
  лучший по частям речи). Подсказки только из служебных слов (местоимения, *be*, *have*, *why*, *what*… — список FUNC в
  [run.py](run.py)) скрыты во всех трёх: закреплённый словарь не может знать, что `SOMEONE(=-5)` здесь — «она».
  Доля слов с подсказкой ([coverage.txt](coverage.txt)): g300 — 24 %, g1000 — 45 %, g3000 — 62 % (39 из 326 скрыты всегда).
  Читатель получает спецификацию mc и [заметку о словаре](tasks/gloss_note.md): слова без `<…>` читать по корням.

По 2 новых читателя Haiku на плечо (6); **все 720 прочтений судят заново** 4 судьи Sonnet (поровну, 30 общих пар по кругу,
10 якорей). Агентов: 6 + 4 = 10.

**Что это измеряет.** Потолок для словаря размера N: кодировщик идеально соблюдает словарь, смысл статьи выбран с оглядкой
на оригинал (подсказки diag1). Настоящий словарь даст меньше.

**Меры** (парный бутстреп, 5000, seed 0): g300 − mc, g1000 − mc, g3000 − mc; для сведения g3000 − mcg, g1000 − tpx.

**Решение после прогона (заранее):**
- **g1000 − mc < +0,2** → словарь обучаемого размера (сотни–тысяча) — не путь: выигрыш придётся на редкие слова, их нужно
  уметь собирать; дальше — конкретные корни и правила сборки (проверять на hold);
- **g1000 − mc ≥ +0,4 и интервал выше 0** → словарь стоит строить; размер (300 / 1000 / 3000 статей против цели «мало слов»)
  решает пользователь по кривой;
- между — словарь помогает умеренно; решать вместе с ценой заучивания.

**Прогноз Claude:** g300 ≈ 1,25, g1000 ≈ 1,5, g3000 ≈ 1,75 (mc ≈ 1,05, mcg ≈ 2,2); g1000 − mc ≈ +0,45.
