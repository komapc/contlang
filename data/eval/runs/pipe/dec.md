# Заранее (2026-11-07, до кодов): многопроходный кодировщик и декодер предложений

Задание пользователя: «хороший (рас)кодировщик», многопроходный — 1) упростить синтаксис, 2) решить, где объединять слова
(мысленно расставить `{}`), иногда наоборот разбить слово на 2–3, 3) кодировать; подумать про «очень». Язык можно менять,
идею оставить. Основание: phrases3 — модель кодирует в 4–6 раз лучше математики, пословно лучше одного слова; круговой перевод
предложений раньше давал ~1,2/3 (clause_rule, математика + правила).

**Предложения** (`pick.py`, Brown, seed 20261107): 8–18 слов, без цифр, кавычек, скобок, `;`/`:`, ≤ 1 имени в середине, ≤ 2 запятых;
поровну из 10 жанров. dev 30 (выбор варианта), holdout 60 (одна проверка победителя в конце). Предложения живые и трудные
(идиомы, *living under a cloud*, *anything but kind*) — так и задумано.

**Спецификация**: текущая, `prepare.py spec enc|dec sents --braces` (45 корней, слова в `{ }`), одна для всех вариантов.

**Кодировщики** (Sonnet, каждый проход — отдельный агент, видит только свой вход):
- **E0** — один проход: исходное предложение → код (нынешний способ).
- **ES** — проход 1 (упростить) → один проход кодирования упрощённого. Отделяет вклад упрощения.
- **E1** — проход 1 (упростить) → проход 2 (расставить `{}`: что одно понятие — одно слово, что разбить на 2–3) →
  проход 3 (закодировать по скобкам). Исходного предложения проходы 2–3 не видят.
- **E1V** — E1 + проверка: слепой Haiku читает код E1 обратно, Sonnet-правщик видит упрощённое предложение, код и прочтение
  и правит неверно прочитанные слова. (reader2 отверг *выбор* по читателю для кодов математики; здесь — правка моделью, другое.)

**Декодеры** (Haiku, слепые, спецификация без задания кодировщика + своё задание):
- **D0** — один проход: код → предложение.
- **D1** — сначала значение каждого слова в `{}` отдельно, потом предложение из них (в одном ответе).

**Мера**: судья Sonnet сравнивает исходное предложение с прочтением, 0–3: 3 тот же смысл; 2 главный смысл, детали потеряны
или искажены; 1 связано (тема, часть смысла); 0 мимо. Пары перемешаны по вариантам, судья не знает вариант. По 2 читателя на
(кодировщик, декодер), среднее; бутстрап по предложениям (5000, seed 0). Доля правильных по правилам слов — для сведения.

**Выбор на dev**: лучший (E, D) по среднему. **Главный критерий — на holdout 60, один раз**: лучший (E, D) − (E0, D0)
≥ +0,25 и нижняя граница 95 % > 0 → предложить многопроходный конвейер (реализация в воркере — PR без слияния до решения
пользователя). Иначе — отвергнут. Для сведения на dev: ES − E0 (упрощение), E1 − ES (скобки), E1V − E1 (проверка), D1 − D0.

**Прогноз Claude** (без порога): упрощение даёт больше всего (+0,3), скобки ≈ 0, проверка +0,1–0,2, D1 ≈ D0.
