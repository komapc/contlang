## Input for this task

Each numbered line is a plain English sentence whose pieces are already marked with { }. Translate it into min-co:
every { } piece becomes exactly ONE min-co word `{ ROOTS | FORM marks }`, with particles (E, AND, LA [ ], [ ], ;) between
words as the spec says. Keep the meaning of each piece in this sentence; small grammar words inside a piece become marks
(not → M-5, very → I+4, more → C+3, past → T-2, will → T+2, plural → N+3, the → D+3, passive → V-4).
Choose roots so that a reader who sees only the code and the spec reads each word back as the piece meant.
