# Значения уточнений: откуда их брать

`make.py` строит коды по корням модели (H) и по корням SZ с разными источниками значений; читались hc и szp (szc, szcr — не читались).
Правило — `../reader/values.py`: прямая связь ConceptNet с полюсом сильнее 0,3 → иначе проекция на ось при |z| ≥ 1,5 → иначе голый корень.

| | близко |
|---|--:|
| H (корни и значения модели) | 38 % |
| Hc (корни модели, значения по правилу) | 31 % |
| HP (корни модели без значений) | 25 % |
| M (корни модели, значения математики) | 24 % |
| SZp (корни SZ без значений) | 16 % |

Значения — главный разрыв: значения математики не лучше голого корня, правило возвращает около половины.
На корнях SZ правило ничего не добавило (см. ../combo). Совпадение знака с моделью: прямые связи ConceptNet 31/32 при покрытии 28 %,
правило — 93 % при покрытии 51 %.
