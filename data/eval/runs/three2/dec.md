# Заранее (2026-10-14, до листов и ответов): умный выбор 2-го и 3-го слова

Цели — те же 188 слов, прочитанные мимо в ../swap (O), что и в ../three. Там W3 (A + LIKE + 2 якоря по рангу математики) дал
+4,8 % [0,0 … +9,6] к A.

Новое: слова выбирает модель читателя (proxy.py — гребневая регрессия от признаков кода к вектору первого ответа, обучена на 4787
прочтениях Haiku из прошлых тестов; для выбора — версия без 188 слов теста). Набор оценивается как cos(n(p(голова)) + β·Σ n(p(слово)), цель),
β = 0,35, штраф 0,01 за слово; слово добавляется, только если оценка растёт. Кандидаты — коды кодера сайта (~4000 лемм) той же части
речи, не синонимы и не то же слово. Строение плоское (A L B L C) или вложенное (A L (B L C)); связка по ребру ConceptNet
(PartOf, AtLocation, HasA → PI; UsedFor → FOR; MadeOf → FROM), иначе LIKE.

Варианты на одних листах (каждый читатель видит слово один раз): **A** (заново), **S** (голова A + 0–2 умных слова),
**HS** (голова — лучшая по модели из 8 кандидатов математики, + 0–2 слова). Спецификация — та же, что в ../three
(DEC_SPEC + строка о нескольких словах, + вложенность в скобках).

Мера — доля первых ответов «близко» (судья Haiku, 2/1/0, «близко» = 2), бутстрап по словам.

**Успех: S − A, нижняя граница 95 % > 0.** Для сведения: HS − A, S − W3 (W3 из ../three, другие читатели), отдельно у слов,
где S добавил слова, и по частям речи. Где S = A (слова не добавлены), код тот же — эти слова входят в S − A как есть.
