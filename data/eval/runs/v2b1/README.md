Целевые − контрольные (по разнице): **+0,44 [+0,07 … +0,83]**. По корням (mc → v2b): `COLOR` 1,0 → 1,7, `SHAPE` 0,9 → 1,6,
`STRONG` 0,8 → 1,4, `LIGHT` 0,4 → 1,0, `OPEN` 0,6 → 1,1, `TRUE` 0,9 → 1,1. Кодировщик v2b употребил свой корень в 40 из 42
целевых (`STRONG` — 5 из 7) и какой-либо новый корень — в 7 из 18 контрольных.

**По правилу из dec.md: корни работают** (≥ +0,25, интервал выше 0, контроль не ниже −0,15). Следующий шаг — v2b против mc и
Toki Pona на dev bench1 (не вредит ли и сколько даёт на обычном тексте, где новых понятий мало), затем hold.

Прогноз Claude был +0,3 (mc 1,1, v2b 1,4): прирост вдвое больше, а mc ниже (предложения roots6 труднее dev: длиннее и
конкретнее). `TRUE` — слабейший, как и ожидалось.

## Как это выглядит

*The room was dark but a neon sign flashed and faded beyond the window.*
- mc: `{ PLACE LIVE | o D+3 } { LIVE(=-2) | i T-2 } ; …` → «The house fell asleep; a lively observer moved and fell asleep…»
- v2b: `{ PLACE INSIDE(=+5) LIVE | o D+3 } { LIGHT(=-5) | i T-2 } ; { LIGHT(=+5) TEXT ART(=-5) | o } { LIGHT(=+5) | i T-2 } AND { LIGHT(=-3) | i T-2 } …`
  → «The home went dark; the screen lit up and then dimmed outdoors.»

Без корня кодировщик v1 подменяет понятие ближайшим (тьма → «сон» `LIVE(=-2)`) или выбрасывает его; с корнем — пишет прямо.

## Оговорки

- **Набор выгоден v2b нарочно**: слова-признаки взяты из глосс корней. Это верхняя граница; на обычном тексте эффект
  умножится на частоту понятий (на dev их касается около 10 из 60 предложений).
- **Кодировщик v2b писал длиннее**: 11,1 корня на предложение против 8,1 у mc (в base1 mc — 6,8). Часть разницы может быть
  разбросом кодировщиков, а не языком; контроль (+0,15, интервал включает 0) и разница целевые − контрольные (+0,44, выше 0)
  говорят, что основная часть прироста — в целевых предложениях. Кавычки: у v2b 11 имён, у mc ни одного.
- **Судьи расходятся в строгости**: s2 ставит в среднем на 0,23 ниже s1, точное согласие на 30 общих парах — 50 % (в base1 и
  retell1 — около 74 %), ±1 — 100 %. Прочтения распределены между судьями случайно и поровну по плечам; у каждого судьи по
  отдельности v2b − mc на целевых одинаков: s1 +0,59, s2 +0,61. Якоря оба судьи ставят близко к ожидаемому (10 из 10 в
  пределах 1).
- Ошибки правил: mc 9 строк из 60 (например, выдуманный корень `REMOVE`), v2b 4.
