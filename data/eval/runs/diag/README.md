# Что в кодах модели несёт смысл

H — коды, написанные моделью (../twowords3). HP — те же корни голыми (без значений), HO — без роли (`agent`, `tool`…).
`make.py` → hp/, ho/; 8 слепых читателей Haiku; оценки — слепой судья (../reader).

| | близко | против H |
|---|--:|--:|
| H | 38 % | |
| HO без роли | 32 % | −6 % (−12 … 0) |
| HP без значений | 25 % | −13 % (−22 … −4) |
| M корни H, значения математики (../taxonomy) | 24 % | HP − M +1 % (−7 … +9) |
| A нынешняя математика | 17 % | |

Значения — главное, что модель знает лучше математики; значения математики для читателя ничего не добавляют к голому корню.
