# Заранее (2026-11-07, до листов): словосочетание одним словом min-co против пословного перевода

Основание: слово min-co уже само по себе словосочетание (главный корень + уточнители, как `tomo moku`), а граница английского
слова случайна (*bedroom* / *living room*). При пословном переводе ошибки двух кодов складываются
([../twowords/README.md](../twowords/README.md): пара кодами математики хуже одного кода, B/A 1,54). В Numberbatch
126 411 двусловных записей с собственным вектором — математика может кодировать фразу так же, как слово.

**Фразы** (`pick.py`, seed 20261107): двусловные леммы WordNet — имена и фразовые глаголы — с вектором фразы в Numberbatch,
оба слова среди 5000 частых слов сайта, частота SemCor ≥ 2, без слитного написания в словаре, без чисел и be/have.
Сложение смысла comp = cos(вектор фразы, среднее векторов слов); нижняя треть — **устойчивые** (fixed), верхняя — **свободные** (free).
По 15 в клетке «имя/глагол × группа» = 60 фраз (`items.json`).

**Варианты** (`codes.js`, вся кодировка — математика сайта `site/math.js`, без LLM):
- **A** — пословно: код сайта каждого слова (`Reader.encode`: лемма, часть речи, смысл), в порядке min-co — главное слово первым
  (у имён — второе английское слово: *air force* → код *force*, затем код *air*; у глаголов — глагол, затем частица).
- **B** — один код из вектора фразы Numberbatch (`Coder.encode`, 3 корня), `| o` у имён, `| i` у глаголов.
- **C** — один код из среднего векторов двух слов (то же, без словаря фраз).

**Чтение**: 6 слепых Haiku — по 2 на вариант, каждый читает все 60 кодов своего варианта (порядок перемешан),
спецификация — `DEC_SPEC` воркера (как у сайта), задание — `reader_task.md` (одинаковое для всех: «код из одного или нескольких
слов min-co означает английское слово или выражение из 1–2 слов»). Судья — слепой Haiku по `judge_task.md`:
пара «фраза — первый ответ», 2 близко / 1 рядом / 0 мимо, без указания варианта.

**Мера** — доля первых ответов «близко» (2), бутстрап по фразам (5000, seed 0).

**Главный критерий**: B − A на всех 60 фразах ≥ +10 п. п. и нижняя граница 95 % > 0 → предложить правило «фраза, у которой
есть вектор, кодируется одним словом min-co» на сайте (решение за пользователем). Иначе гипотеза отвергнута.

**Вторичное** (для сведения, без порога): B − A и C − A по группам fixed / free и по частям речи; B − C
(ожидание: B > C на устойчивых, B ≈ C на свободных); доля «рядом».

Оговорки, известные заранее: деление на группы по comp шумное (Numberbatch: *training program* попало в устойчивые);
у вариантов B и C ответ-одно-слово тоже может быть «близко» (*firetruck* для *fire engine*) — так и задумано.
