# Словосочетание одним словом min-co (2026-11-07)

Порог — [dec.md](dec.md) (закоммичен до листов). 60 двусловных выражений WordNet с вектором фразы в Numberbatch
(15 × имена/фразовые глаголы × устойчивые/свободные по comp = cos(фраза, среднее слов)), `items.json`.
Коды — математика сайта (`codes.js`): **A** пословно (код сайта каждого слова, главное первым), **B** один код из вектора фразы,
**C** один код из среднего векторов слов. По 2 слепых Haiku на вариант (все 60 кодов, `reader_task.md`), судья Haiku 2/1/0
(`judge_task.md`, `judge/`, `labels.json`).

## Итог ([result.txt](result.txt), [table.md](table.md))

| — устойчивые | 7 % | 23 % | +16,7 % [+5,0 … +30,0] | 30 |

C − A +5,0 % [−1,7 … +12,5]; B − C +7,5 % [−1,7 … +16,7]. «Близко или рядом»: A 38 %, B 62 %, C 42 %.

**Порог пройден** (≥ +10 п. п., нижняя граница > 0). Выигрыш дают в основном фразовые глаголы: figure out
`THINK(=+2) KNOW(=+2) CAN(=-1) | i` → understand (пословно — brain), turn down → turn down (пословно — look back),
go wrong, break with → separate (пословно — enroll), cast aside → give up. Пословно частица (*up, out, on, down*)
получает свой код-обстоятельство и уводит чтение. У имён выигрыш мал и не значим: low temperature `HEAT(=-1) | o` → cold,
first step → beginning, но old woman `SEX(=-3) | o` → woman (рядом) — один корень теряет «старая».
Против B: rush out → spit out, fall behind → fall.

Сложение векторов слов (C) даёт меньше, чем вектор фразы (B): выигрыш — от знания самой фразы, не только от «одного кода вместо двух».

Оговорки: 60 фраз, Haiku-читатели; деление на устойчивые/свободные по comp шумное; оба слова фраз — из частых 5000.
Ввод правила («выражение со своим вектором — одно слово min-co», в первую очередь фразовые глаголы) — решение пользователя.
