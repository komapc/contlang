# axes2: пересмотр корней, шаг 2 — имена главных осей и шкалы смысла

Пороги — dec.md (с поправкой про полюса из полного Numberbatch). Пространство — шаг 0 (../../../pca_axes.md, space.npz, space.py).

## 2а. Имена 20 осей varimax (naming/)
Два независимых Haiku (видели только полюса) назвали все 20 осей **«две несвязанные темы»**, не шкалами; имена у двух почти
совпали: решения и заявления | рост и открытия; экономика | дом и еда; время и порядок | чувства; деньги | прорывы;
насилие | чиновники; парламент | личная жизнь; спорт | правительство; армия | экономика; бизнес | религия… Повёрнутые главные оси —
области (темы), а не шкалы «−5 … +5».

## 2б. Шкалы по словам-полюсам (proposals/, select.py → candidates.json, selection.md; intrude.py → intrusion.md)
Два Haiku (без min-co) предложили 80 шкал; после слияния дублей — 55. Десять из них совпали с осями нынешних корней
(|cos| > 0,7): холодное–горячее ≈ HEAT, твёрдое–мягкое ≈ TOUCH, громкое–тихое ≈ SAY, большое–малое ≈ BIG, близко–далеко ≈ NEAR,
живое–мёртвое ≈ LIVE, весёлое–грустное ≈ MOOD, дать–взять ≈ GIVE, соединить–разделить ≈ JOIN, наружное–внутреннее ≈ INSIDE.

| набор (жадный отбор, abs(cos) ≤ 0,3) | k = 10 | k = 15 | k = 20 | лишнее слово (k = 20) |
|---|--:|--:|--:|---|
| новые шкалы Haiku | 5,5 % | 7,9 % | 10,1 % | 61 % [51 … 71] |
| оси корней (слова semaxis) | 5,7 % | 8,1 % | 10,3 % | 57 % [48 … 66] (38 осей) |
| оба пула | 5,8 % | 8,3 % | 10,6 % | |
| атомы корней (обученные) | 6,7 % | 9,5 % | 12,1 % | |
| PCA (потолок) | 11,6 % | | 19,9 % | 64 % [51 … 76] |

Покрытие — доля дисперсии очищенных векторов в линейной оболочке набора (на big1000 — то же с точностью 0,5 %). Лишнее слово:
4 слова полюса + 1 чужое, два читателя Haiku на задание, случайно 20 %. Осгуд (3 оси) — 1,5 %.

**По правилу dec.md к шагу 4 не идти:** новые шкалы покрывают не больше осей корней (7,9 против 8,1 % при k = 15, 10,1 против
10,3 % при k = 20), понятность в пределах шума. Нынешние оси корней — уже почти тот же набор, который модель предлагает как
«естественные шкалы», а обученные атомы покрывают больше любых осей по словам.

Что из новых шкал стоит запомнить (нет среди корней, читаются хорошо): мирное–жестокое (100 %, близко к FRIEND −0,54),
больное–здоровое (100 %), открытое–закрытое (88 %), общее–частное (88 %, близко к RULE), создать–разрушить (75 %),
законное–незаконное (75 %), важное–пустяковое (38 %, близко к VALUE), постоянное–временное (62 %).
Оси корней, у которых вектор плохо читается по своим словам (0 %): THINK, TIME, PART, CONSUME — это про направление в векторах,
а не про определение корня для читателя.

Главный вывод шагов 1–2: 20 любых осей с именами покрывают около половины того, что PCA-20, а PCA-20 — лишь 20 % дисперсии.
Смысл слов в этих векторах не сводится к 10–20 шкалам; крупные направления — темы (области), то есть головы, а не оси.
