# senses: смыслы многозначного слова — раздельными кодами

Правило решения — dec.md (записано до чтения). Слова и смыслы — make.py → items.json.
Коды кодера сайта по вектору смысла — senses.js → codes.json. Читатели, судьи и итог — run.py readers|pairs|score SCRATCH.

Итог (result.txt): **разницы нет**, sense 18 % против one 20 % «близко», разница −2 % [−10 … +5].
По смыслу 1 и по смыслу 2 отдельно то же самое.
Отдельные слова выигрывают (step, head, draft, test — table.md), но столько же проигрывают.
Сдвиг вектора к опорным словам смысла меняет коды у 95 слов из 100, но читаются они не лучше.
Узкое место — сам кодер (три корня, которые не складываются в смысл), а не смешение смыслов.
