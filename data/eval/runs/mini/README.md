# mini: конвейер PR #19 на модели воркера (gpt-5-mini) — результат (2026-11-10)

Заранее: [dec.md](dec.md). 60 предложений holdout из pipe. Код воркера из ветки `worker-sent` — в `w/` (без изменений),
вызов OpenRouter — `run.mjs`; чтение и судьи — `run.py`. Коды — `enc.json`, `codes.json`; прочтения — `answers/`,
`dec_gpt.json`; оценки — `judge/`; итог — [result.txt](result.txt).

| код | читатели Haiku, среднее /3 | ≥ 2 | читатель gpt-5-mini |
|---|---|---|---|
| M0 — gpt-5-mini, один проход | 1,22 | 30 % | 1,23 |
| MV — gpt-5-mini, своё чтение + правка (PR #19) | 1,23 | 23 % | 1,23 |
| S — конвейер Sonnet из pipe (E0V) | **1,62** | 35 % | — |

- **Критерий 1 не выполнен**: MV − M0 = +0,01 [−0,13 … +0,15] (у читателя gpt-5-mini +0,00). На gpt-5-mini петля
  «прочитать → исправить» ничего не даёт.
- **Критерий 2 не выполнен**: MV − S = −0,39 [−0,59 … −0,20] (порог −0,25). Без 3 сбоев (правило «нет кода = 0» добавлено
  после dec.md): −0,32 [−0,50 … −0,13] — вывод тот же, но запас до порога небольшой.
- Сбои: 3 из 60 предложений модель трижды не вернула JSON (на сайте была бы ошибка; здесь 0 баллов у M0 и MV);
  11 из 57 кодов после правки нарушают правила.

Гипотеза (не проверена этим прогоном): правка gpt-5-mini косметическая — на просмотренных примерах она меняет метки и
порядок, а неверно прочитанные слова оставляет (*Place kicking is largely a matter of timing* → прочитано «движение в
месте… Moritz сказал», правка не изменила ни слова). S отличается от MV сразу всем: кодировщиком, читателем в петле,
правщиком, усилием рассуждения — что из этого даёт разницу, здесь не выделено.

Для сведения: один проход gpt-5-mini (1,22) и один проход Sonnet в pipe (E0 1,03) примерно равны, но не сравнивались
в одном прогоне; S здесь получил 1,62 против 1,35 в pipe — разброс читателей и судей между прогонами ≈ 0,3, сравнивать можно
только внутри одного прогона.

**Вывод**: PR #19 в нынешнем виде (всё на gpt-5-mini) мёржить незачем — он втрое дороже одного прохода и не лучше;
кроме того, 3/60 предложений без ответа — дефект режима. Следующий дешёвый опыт: сильный правщик (Sonnet) поверх уже
готовых `first` и `readback` gpt-5-mini, с M0 и S как якорями в том же прогоне — покажет, хватает ли сильной модели
на одном шаге.
