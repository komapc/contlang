# Пороги (до ответов)
Обученный словарь на 44 и на 47 корнях (learn.py, тот же способ, что у сайта), кодер SZ с одной выраженностью у всех корней.
160 слов из пула ../adopt: по 40 изменённых на LAND, SACRED, CONTAINER и 40 изменённых без новых корней (побочный сдвиг).
2 слепых читателя Haiku на код, судья ../reader, метрика — «близко», парный бутстрап по словам.

- **Новые корни доказаны**, если на 120 словах с новыми корнями new − old > 0 с нижней границей 95 % > 0
  **и** на 40 словах побочного сдвига разница ≥ −5 % (по точке).
- По корням (40 слов): корень с разницей ≤ 0 к принятию не предлагать.
- Итог по словарю (пул 3516): доля изменённых с новыми корнями × разница + доля побочных × разница.
