# Честная проверка новых корней: обученный словарь на 47 корнях

`learn.py` обучает словарь на 44 и на 47 корнях тем же способом, что у сайта (scripts/18_sparse_learn.py; dict44 совпадает
с site/data/math.json: cos центров 0,98). Полюса новых корней — списки слов в learn.py. `make.py` кодирует пул ../adopt
кодером SZ (одна выраженность у всех корней) и берёт 40 изменённых слов на корень + 40 изменённых без новых корней.
Пороги — dec.md. 2 слепых читателя Haiku на код, судья ../reader; `score.py` → result.txt.

| | 44 корня | 47 корней | разница (95 %) |
|---|--:|--:|---|
| с новыми корнями, 120 слов | 15 % | 18 % | +2 % (−5 … +10) |
| LAND | 6 % | 26 % | **+20 % (+9 … +31)** |
| SACRED | 18 % | 10 % | −8 % (−22 … +6) |
| CONTAINER | 22 % | 16 % | −6 % (−16 … +2) |
| побочный сдвиг, 40 слов | 18 % | 10 % | **−8 % (−15 … −1)** |

По порогам: новые корни **не доказаны** (общая граница < 0, побочный сдвиг −8 %). LAND проходит по корню; SACRED и CONTAINER — нет.
Пул 3516: новые корни есть в 19 % кодов, побочные изменения — ещё 21 % (переобучение сдвигает старые атомы).

После ответов (не заявлено): новый корень родом — LAND +27 %, CONTAINER +17 % (6 слов), SACRED +4 %; уточнением —
LAND +16 %, SACRED −13 %, CONTAINER −10 %. Математика ставит SACRED и CONTAINER уточнением туда, где их нет
(tradition, solidarity, dutch; chip, surface, savings).
