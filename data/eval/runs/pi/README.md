# PI у кодера сайта: что не так и чем заменить второе слово (2026-10-14)

Вопрос пользователя: прежде чем убирать пару через PI у кодера сайта, поискать лучшее определение или применение.
Слова: все 137 кодов-пар кодера сайта из ../big1000 (кодер ставит пару, когда векторы не ставят слово первым по его коду:
голова + `PI` + ближайший сосед слова, закодированный не более чем двумя корнями). Пороги — в `dec.md`, записаны до чтения.

Варианты (`make.py` → `codes.json`; слепые читатели Haiku по 42–46 кодов, нынешний DEC_SPEC; судья Haiku 2/1/0):
- A — код сайта как есть; B — только голова;
- F — голова + `PI` + ближайшее по вектору опорное слово — рецепт из `site/data/recipes.json` (127 имён, коды проверены);
- D — голова + связка по типу ребра ConceptNet к опорному слову (PartOf / AtLocation / HasA⁻¹ → PI, UsedFor → FOR,
  MadeOf → FROM, вес ≥ 2; иначе RelatedTo ≥ 2 → PI; иначе только голова — так у 95 слов из 137);
- G — коды F, читатель с более широким PI: «X belongs to Y's field: part of Y, found in Y, or a kind of Y» (`spec_g.md`);
  A2 — коды A с тем же определением.

| вариант | близко | рядом |
|---|--:|--:|
| A сайт | 19 % | 49 % |
| B только голова | 23 % | 42 % |
| F + опорное слово | 24 % | 54 % |
| D + связка по ConceptNet | 18 % | 49 % |
| G = F, широкий PI | 26 % | 49 % |
| A2 = A, широкий PI | 20 % | 38 % |

Разницы (`result.txt`): B − A +3,6 % [−3,6 … +11,7]; F − A +5,1 % [−3,6 … +14,6]; F − B +1,5 % [−6,6 … +9,5];
D − B на 42 словах с ребром −16,7 % [−33 … 0]; G − B +2,9 % [−5,1 … +11,0]; G − A +6,6 % [−2,2 … +14,6]; A2 − A +0,7 %.

Выводы (по `dec.md`):
1. Нынешняя пара пользы не даёт (B не хуже A): второе слово — случайный сосед, закодированный двумя корнями, читатель его не узнаёт.
2. F не принят (+5 % к A при пороге +8 %, к B ≈ 0). Опорное слово тянет ответ в поле («рядом» 54 % против 42 %), но
   ближайшее по вектору опорное слово — чаще род или синоним, а читатель понимает PI строго как «часть Y»:
   rifles + gun → barrels, poles + ice → icicles, step + number → digit.
3. Типы связок по ConceptNet вредят: рёбра шумные (credit UsedFor car, poles RelatedTo north, cotton AtLocation medicine).
4. Широкое определение PI не помогает заметно (G − B +2,9 %) и залезает на FOR (шайба — FOR игра, не PI).
5. Узкое место у этих слов — голова: код главного слова промахивается (diabetes `BODY MEASURE(=-3) ABOVE(=-4)` → foot),
   второе слово его не спасает. При этом сама пара хороша, когда части читаемы: в ../twowords3 пара словами — 103 из 200
   первыми, «X кодом + Y словом» — 60 из 200 против 38 у одного кода модели.

Слова только трудные (те, где кодер ставил пару), интервалы ±8 %. `table.md` — все коды и первые ответы.
