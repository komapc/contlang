# Заранее (2026-11-07, до листов): свободные словосочетания — свёртка в одно слово по правилам грамматики

Основание: [../phrases](../phrases/README.md) — один код из вектора фразы лучше пословного (+12,5 %), но выигрыш в основном
у устойчивых фразовых глаголов, а на свободных сочетаниях усреднение векторов слов (C) ничего не дало (+1,7 %).
Вопрос пользователя: выигрывают ли свободные сочетания «признак + имя», «наречие + глагол» («быстро идти», «очень хочу»,
«сильный дождь»). Гипотеза: выигрыш идёт не от векторов, а от грамматики min-co — метки степени `I`, сдвига значения оси,
отбрасывания пустого глагола; слова степени сейчас кодируются почти случайно (*very* → `GOOD(=0) MANY(=+2) BIG(=-1) | e`).

**Фразы** (`cand.py`, `pick.js`, seed 20261107): двусловные записи Numberbatch, оба слова среди 5000 частых слов сайта, фразы нет
среди лемм WordNet (свободные, не устойчивые), слова — базовые формы, не имена. По 15 в классе:
- **deg** — слово степени (`deg.json`) первым: наречие степени + признак или глагол, прилагательное степени + имя;
- **light** — глагол-связка (make, take, give, have, do, get, pay) + имя действия с родственным глаголом WordNet;
- **axis** — признак + главное слово (прил. + имя, глагол + наречие), лучший одиночный корень признака есть в коде главного слова;
- **indep** — прилагательное + имя, лучший корень признака не в коде имени.
Относительные прилагательные (*political* ← politics) исключены из axis и indep.

**Варианты** (`codes.js`, математика сайта и правила, без LLM):
- **A** — пословно, коды сайта двух слов, главное первым (у связки — глагол первым);
- **F** — одно слово по правилам класса: deg — код главного + `I` (very +4, slightly −2 …); light — код родственного глагола
  (decision → decide) с `| i`; axis — значение общего корня сдвинуто на значение признака (run fast: MOVE +2 → +4; если там 0 —
  как indep); indep — 2 лучших корня главного слова + лучший корень признака;
- **B** — один код из вектора фразы Numberbatch.

**Чтение и судья** — как в ../phrases: 6 слепых Haiku (по 2 на вариант, все 60 кодов), `DEC_SPEC` без его задания + `reader_task.md`;
судья Haiku 2/1/0 по `judge_task.md`. Мера — доля первых ответов «близко», бутстрап по фразам (5000, seed 0).

**Главный критерий**: F − A на всех 60 ≥ +10 п. п. и нижняя граница 95 % > 0 → предложить свёртку свободных сочетаний
по правилам (решение за пользователем). Иначе отвергнута.

**Прогнозы по классам** (записаны заранее, без порога, n = 15 — только направление):
- пользователь: выигрыш прежде всего у «признак + имя» и «наречие + глагол» (axis, indep) и у степени (deg);
- Claude: F − A большой у deg и light, малый у axis, около нуля у indep.
Для сведения: B − A, B − F по классам; «рядом».

Оговорки, известные заранее: классы по правилам шумные (*black chamber*, *white air*, *anti aircraft* попали в выборку);
n = 15 в классе — разница внутри класса значима только при большом эффекте.
