# Три слова для неудачных слов (2026-10-14)

Вопрос пользователя: поможет ли разрешить до трёх слов в коде; эксперимент на неудачных словах. Пороги — [dec.md](dec.md).
- Цели: 188 слов, нынешний код которых слепой читатель прочитал мимо в ../swap.
- Опорные слова (`pool.py`, 469): рецепты сайта и коды сайта, прочитанные слепым читателем «близко»; той же части речи, не того же корня, не синонимы.
- `search.js` (48 мин): W2 = код + `LIKE` + опорное слово, W3 = W2 + `LIKE` + второе; выбор по месту цели при чтении векторами.
  У 117 из 188 целей математика и так ставит цель первой, поэтому место опорные слова почти не различает — при равенстве берётся ближайшее по вектору.
- `run.py readers|pairs|merge|score` → spec.md (DEC_SPEC + строка о нескольких словах), lists.json, answers/, judge/, result.txt, table.md.

опорные слова не подсказывают ответ, а сдвигают его.

Итог: порог («нижняя граница > 0») не пройден на самой границе — нижняя граница ровно 0 (в 3,6 % бутстрап-выборок разница ≤ 0).
Сдвиг в нужную сторону и монотонный (A < W2 < W3). Выигрыши: academy (contest → academy; navy, school), death (ghost → death;
funeral, tragedy), villages, diplomatic, governmental, generated → produce, intent → plan, prevent → avoid, emerge, gain.
Потери: question → essay (idea, investigation), thoroughly → usually, obstacle → shield (road, enemy), syndrome → accident (article, theory).

Оговорки: слова трудные (A после повторного чтения — 9 %), так что на всём словаре эффект меньше; опорные слова выбраны грубо
(место у математики почти всегда 1). Лучший выбор опорных слов — главный рычаг, если продолжать.
