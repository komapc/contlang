# Заранее (2026-10-14, до листов и ответов): три слова для неудачных слов

Вопрос пользователя: поможет ли разрешить до трёх слов в коде; «поэкспериментируй с неудачными словами».
Только кодер сайта (математика), без модели.

- Цели: 188 слов, нынешний код которых слепой читатель прочитал мимо (0) в ../swap (вариант O, оба теста; слова, которые в другом листе прочитаны «близко», исключены).
- Опорные слова (pool.py): коды, проверенные слепым чтением, — рецепты сайта без пар, коды сайта, прочитанные «близко» в ../swap
  и в ../big1000 (если код с тех пор не изменился); той же части речи, что цель, не того же корня (первые 5 букв), не синонимы WordNet; 30 ближайших по вектору.
- Варианты (search.js; связка всегда LIKE, выбор — по месту цели при чтении векторами, Reader.scores):
  - **A** — нынешний код (читается заново: цели отобраны по промаху, без повторного чтения выигрыш завышен);
  - **W2** — A + `LIKE` + одно лучшее опорное слово;
  - **W3** — W2 + `LIKE` + второе лучшее опорное слово.
- Спецификация читателя для всех трёх вариантов одна: DEC_SPEC сайта и строка о нескольких словах (`X LINK Y LINK Z`, каждое следующее
  уточняет первое; `LIKE` годится и для глаголов, признаков, наречий).
- Один слепой читатель Haiku на код (~47 кодов на лист, у листа один вариант, слово на разных листах у разных читателей), судья Haiku 2/1/0,
  мера — доля первых ответов «близко», парный бутстрап по словам (5000).

Правила:
- **Три слова помогают**, если W3 − A: нижняя граница 95 % > 0.
- Для сведения: W2 − A, W3 − W2 (добавляет ли третье слово), по частям речи; сколько ответов совпадает с опорным словом.
- Оговорка заранее: если ответ читателя — само опорное слово, а оно близко к цели, это засчитывается как «близко»: так и задумано
  (уточнение «похоже на Y»), синонимы и однокоренные исключены отбором.
- Решение — за пользователем.
