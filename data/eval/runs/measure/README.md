# Значение как измерение

Вопрос (после ../taxonomy): значения математики плохие — а если значение не подгонять, а *измерять*? z — z-оценка проекции слова на ось a_r
по словарю сайта; значение = голый корень при |z| < 0,5, иначе ±5 со знаком z (пороги Z0 = 0,5, Z2 = 2 не подбирались; решение — `dec.md`, записано до ответов).

- **MZ** — корни, порядок и форма из кода модели H, значения — измерение (диагноз).
- **TZ** — корни варианта T (род по таксономии + уточнения математики), значения уточнений — измерение.
- **SZ** — без подгонки суммы: род по таксономии (без рода — самый выраженный корень), уточнения — самые выраженные корни по |z|
  (первое всегда, второе при |z| ≥ 2), значение по измерению. 2,6 корня на слово.

`node make.js` → items.json, {mz,tz,sz}/codes_K.md; 12 слепых читателей Haiku (по 2 на половину); `MEAS=1 ../twowords3/score.py` → score.txt.
`flips.js` → flips.txt: где знак измерения спорит со значением модели (|v| ≥ 3).

| вариант | место |
|---|--:|
| A нынешний | 142 |
| T род по таксономии | 134 |
| M корни модели, значения математики | 122 |
| **MZ** корни модели, значения измерения | 166 |
| **TZ** корни T, значения измерения | 117 |
| **SZ** род + выраженные оси, без подгонки | **104** |
| H код модели | 60 |

- MZ/H 2,78 (95 % 1,8–4,3), MZ/M 1,36 (0,97–1,89): измеренные знаки *хуже* подогнанных. Проекция на ось не знает того, что знает модель:
  знак спорит со значением модели в 29/113 случаях, разбросанно по корням (ABOVE 4/6: religion, crater, planet; JOIN 3/8), обычно при |z| < 1 —
  и такой слабый знак печатается громким ±5. Дело в самих осях, а не в подгонке.
- SZ/A 0,73 (0,46–1,15), SZ/T 0,78 (0,52–1,11), TZ/T 0,87 (0,65–1,17): по порогу — не лучше. SZ — лучшее число математики за все прогоны,
  но доверительный интервал покрывает 1; повтор со свежими читателями нужен, прежде чем на это опираться.
- (=0) здесь печатается только у рода из таблицы (THING(=0) и т. п.); идеи «(=0) — середина оси» не проверялись.
