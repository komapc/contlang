# Заранее: правки 1, 2, 3, 5 (после big1000)

Слова: 200 из ../big1000 — все 130 существительных с ролью по WordNet (первый смысл: noun.person → agent,
noun.attribute → quality, noun.artifact с гиперонимом device / instrument / tool / implement / machine / weapon / utensil → tool)
и 70 случайных остальных. База (A) — код сайта и его прочтение из ../big1000.

- **V1 (5)** — коды A, спецификация читателя с новыми осями 8 корней (LONG, KNOW, MEASURE, TOUCH, NEAR, GIVE, VALUE, CARE).
  Оси переписаны по ближайшим словам атомов c + s·v·a при v = −5, 0, +5 (atoms.js, atoms.txt).
- **V2 (2 + 3)** — кодер сайта с уровнями только −5, 0, +5 (THING −5, 0, +4; SEX −5, +5); 0 пишется голым корнем.
  2 корня; третий — если cos растёт больше чем на δ, δ — 70-й перцентиль прироста на этих 200 словах (третий корень у ~30 %).
  Второе слово через PI — как на сайте (п. 4 отложен). Спецификация прежняя.
- **V3 (1)** — V2 плюс роль из WordNet (`| o agent`, `| o tool`, `| o quality`) у 130 слов с ролью. В спецификации у agent
  добавлено «или человек этой области». Только эти 130 слов.

Читатели — слепые Haiku, по 50 кодов, у каждого коды одного варианта. Судья — как в ../big1000 (2/1/0), метки в ../reader/labels.json.
Мера — доля «близко» первого ответа, парный бутстреп по словам.
- V1 − A и V2 − A на 200 словах; V3 − V2 и V3 − A на 130 словах с ролью.
- Правка принята в тест-кандидаты, если нижняя граница 95 % > 0. Решение о языке — за пользователем.
