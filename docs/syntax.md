# Синтаксис

## Частицы

Связь слов в предложении задаётся частицами (четыре из Toki Pona, `PE` и `AND` добавлены). Конструкции вкладываются друг в друга. Частицы и суффиксы частично дублируют друг друга (суффикс `-i` уже говорит «глагол», а `LI` отмечает сказуемое); решено: `LI` остаётся отдельным словом (маркер сказуемого).

| Частица | Роль |
| :-- | :-- |
| `LI` | маркер сказуемого |
| `E` | прямое дополнение |
| `PI` | группировка модификаторов |
| `LA` | условие / контекстная клауза |
| `PE` | деятель при страдательном залоге (кем): `… V-4 PE X` |
| `AND` | сочинение «и, также»: между словами, группами и клаузами |

## Слово: смысл | форма

Слово записывается как **`ROOT(=v) ROOT(=v) … | pos метки`**. До `|` стоит смысл: главный корень и до двух корней-модификаторов, у каждого при необходимости значение его оси `(=v)`. После `|`: часть речи и грамматические метки. Корни пока английские глоссы ([фонология](phonology.md)).

| Часть речи | Значение | Пример |
| :-- | :-- | :-- |
| `o` | имя (предмет, понятие) | `MOVE \| o` — движение |
| `i` | глагол (действие, состояние) | `MOVE \| i` — двигаться |
| `a` | признак (определение) | `MOVE \| a` — подвижный |
| `e` | обстоятельство (образ действия) | `MOVE(=+4) \| e` — быстро |

Любой корень берёт любую часть речи (семьи слов, конверсия вроде *work*).

**Метки формы** (не корни, не входят в лимит трёх; пропуск = не указано, как всегда):

| Метка | Значение | Пример |
| :-- | :-- | :-- |
| `T` | время: −5 давно … 0 сейчас … +5 когда-нибудь | `T-2` прошлое, `T+2` будущее |
| `N` | число: 0 нет … +5 все (как ось `MANY`) | `N+3` несколько, `N0` ни одного |
| `M` | вероятность: −5 точно нет … −3 может быть … +4 наверняка | `M-5` не |
| `A` | вид: −5 вот-вот начнётся … 0 идёт … +5 закончено | `A-4` начал, `A+5` закончил |
| `C` | сравнение: −3 меньше, +3 больше, +5 самый (больше или меньше того, что назван корнем: `GOOD \| a C+3` лучше, `C-3` хуже) | `BIG \| a C+5` самый большой |
| `I` | интенсивность (насколько сильно проявлен признак или действие): −5 едва … −2 слегка … +2 довольно … +5 чрезвычайно; `I0` не писать (декодер его теряет), для «умеренно» брать `I+1…+2`; не сравнение (для него `C`) | `GOOD(=+3) \| a I+4` очень хороший; `GOOD \| a I-4` едва хороший |
| `K` | побуждение, каузатив (подлежащее воздействует на дополнение `E`, чтобы оно совершило или претерпело действие глагола): −5 помешать, отговорить, запретить … 0 допустить … +5 заставить, вызвать, побудить; без корня действия база — `DO` | `DO \| i K+4 E SOMEONE` — заставил его; `CONSUME \| i K+4 E SOMEONE` — накормил; `DO \| i K-4 E SOMEONE` — помешал ему |
| `D` | определённость: −3 неопределённое (*a*), +3 определённое (*the*) | `PLACE LIVE \| o D+3` — этот дом |
| `R` | событие относительно опорной точки (Рейхенбах: E↔R; `T` задаёт R↔сейчас): −3 раньше опорной точки, 0 одновременно, +3 позже | `T-2 R-3` — уже ушёл (до того); `T-2 R+3` — позже (в прошлом); `T+2 R-3` — к тому времени уйдёт |
| `V` | залог: −4 подлежащее претерпевает (страдательный), 0 происходит само (нет действующего), +4 подлежащее действует намеренно | `PART \| i T-2 V-4` — было разделено; `PART \| i V0` — разделилось само |
| `!` `?` | приказ, вопрос (без значения) | `CONSUME \| i !` — ешь! |

**Опорная точка R** по умолчанию — ближайшее названное время или событие слева (в начале текста — момент речи); явно её задаёт клауза `LA [ … ]` (*после того как…*) или дата в кавычках. `R` не вид: `A` про фазу самого события (начало, процесс, конец), `R` про порядок во времени.

`THING(=+4) BIG(=+5) | o N+3` — слоны (три корня не тратятся на число). `MOVE NEAR(=+4) | i T-2 M-5` — не пришёл. Метки ставятся один раз на главном слове группы.

Старые части ниже («Время и отрицание», примеры) описывают то же через признаки `(TIME=…)` и суффиксы `-o/-i`: это прежняя запись, смысл тот же.

## Время и отрицание (принято)

Время и отрицание — метки формы `T` и `M` после `|` (таблица выше), а не корни. Пропуск = не указано ([правило нуля](model.md)).

- **`T`** — время от −5 («очень давно») через 0 («сейчас») до +5 («когда-нибудь»): `T-1` только что, `T-3` давно, `T+1` скоро. Без метки время не указано.
- **`M`** — вероятность утверждения: простое утверждение — по умолчанию, метки нет; `M+4` наверняка, `M-1` вероятно, `M-3` может быть (50/50), `M-4` вряд ли, `M-5` точно нет. «Может быть, да» и «может быть, нет» различаются только степенью. Отрицание, «может быть» и «наверняка» — одна метка; отдельной частицы отрицания нет.

Смысловой корень `TIME` слева от `|` (`TIME(=-2) | e` — «вчера», `FEEL(=+4) GOOD(=-4) TIME(=+3) | i` — «бояться») и метка `T` справа не смешиваются. Локальная ось корня пишется `(=v)`: `LIVE(=-2) | i` — «наполовину жив» (спит), `LIVE | i T-2` — «жил».

*She did not see the message* (HEAR убран: слух читается через SEE и SAY; запись фразы пока старая, с частицами):

```
SOMEONE-o LI SEE-i(TIME=-2) M-5 E THING-o PI SAY-o
```
эквивалентно `SOMEONE | o`, затем `SEE | i T-2 M-5`, `E`, `THING | o PI SAY | o`.

Число и местоимения — следующий шаг ([план](roadmap.md)).

## Группа существительного, клаузы и вопросы (принято)

- **Главное слово первым, модификаторы после** (как в Toki Pona). Прилагательные (`-a`) идут сразу за существительным без частицы, плоским списком, и все относятся к нему: `THING-o MOVE-a BIG-a(=3) RGB(255,0,0)` — большая красная движущаяся вещь.
- **`PI`** вводит существительное, определяющее главное («из», составное слово), и идёт после прилагательных: `SOMEONE-o BIG-a PI SOMEONE-o MANY(=+4)` — большой человек народа (правитель).
- **`LA`** — условие, контекст и причина («если», «когда», «потому что», «хотя»): `LA [ … ] …`. Клауза с `LA` стоит перед главной, поэтому «поэтому X» передаётся перестановкой: причина идёт в `LA [ … ]`, следствие после неё (`LA [ он болел ] он остался дома`). Если порядок слов приходится менять, его меняют.
- **`AND`** — «и, также»: стоит между сочиняемыми словами, группами и клаузами и связывает то, что слева, с тем, что справа: `LIVE | i AND SAY | i` — *жил и говорил*, `[ … ] AND [ … ]`. В перечислении ставится перед последним элементом. Частица берёт оси как слово: `AND SAME(=-5)` — но, `AND SAME(=-2)` — хотя, `AND HAPPEN(=+4)` — поэтому, `AND HAPPEN(=-4)` — потому что, `AND BIG(=+4)` — тем более, `AND | M-3` — или (метка вероятности, не корень); порядок слов исходный ([encoding](encoding.md)). Отдельная частица, поэтому `JOIN`, `CHANGE`, `SAME` как связки не писать (они означают присоединение, изменение, тождество).
- **Клауза-содержание** (после *думать, сказать, знать, хотеть*) берётся в скобки как дополнение: `THINK-i E [ … ]`. Устный маркер скобок — вопрос для фонологии.
- **Вопрос** — запрошенное значение `?`: да/нет — метка `?` на сказуемом, «кто/что» — `SOMEONE-o(?)`, `THING-o(?)`. Отдельного слова вопроса нет.
- **Даты и время суток:** `DATE(month=3, day=5)`, `CLOCK(3:00)`.

*Who said that the king is dead?*

```
SOMEONE-o(?) LI SAY-i(TIME=-2) E [SOMEONE-o BIG-a PI SOMEONE-o MANY(=+4) LI LIVE-i(=-5)]
```

## Пропущенные значения и «не важно»

Действует [правило нуля](model.md): ось не написана — значение не указано (ничего не стоит по битам); `(=0)` — явная середина двусторонней оси (у односторонней, как MANY, — настоящий ноль). `MOVE-i` — «двигаться» без уточнения скорости, `MOVE-i(=0)` — «идти обычным шагом».

- Если значение действительно **не важно**, ось просто не пишется. Отдельный маркер `?` нужен только для запроса («какое значение?»).
- Прежнее решение «пропуск = середина шкалы» и вариант «признак — интервал `[-5, +5]`» сняты: первое противоречит правилу нуля, второе не понадобилось.

## Примеры

**Исторический материал.** Примеры ниже записаны старой схемой (корни `HUM`, `BE-BORN`, признаки `QUANTITY`, `AGENCY`, …) и в текущем списке корней не читаются. Они оставлены как иллюстрация структуры предложения (`LI`, `LA`, скобки); актуальные коды слов — в [словаре](lexicon.md) и скилле `mincode`.

**All humans are born free and equal.**

```
HUM-o(QUANTITY=5) LI BE-BORN-i(TENSE=-2) LA HUM-o PI AGENCY=5 PI IMPORTANCE=0
```

**Some people fear authority.**

```
HUM-o(QUANTITY=-3) LI FEAR-i(INTENSITY=4) E RULE-o(AGENCY=5)
```

**If someone acts freely, society benefits.**

```
HUM-o(QUANTITY=-3) LI DO-i(AGENCY=5, CERTAINTY=4) LA SOCIAL-LIFE-o LI GROW-i(GOODNESS=4)
```

> Конкретные числа (`QUANTITY=-3`, `IMPORTANCE=0` для «equal») — моя интерпретация, шкалы пока не откалиброваны.
