# Синтаксис

## Частицы

Связь слов в предложении задаётся четырьмя частицами из Toki Pona. Конструкции вкладываются друг в друга. Частицы и суффиксы частично дублируют друг друга (суффикс `-i` уже говорит «глагол», а `LI` отмечает сказуемое); как их совместить, пока не решено ([план](roadmap.md)).

| Частица | Роль |
| :-- | :-- |
| `LI` | маркер сказуемого |
| `E` | прямое дополнение |
| `PI` | группировка модификаторов |
| `LA` | условие / контекстная клауза |

## Слово: корень, суффикс, признаки

Слово записывается как **`ROOT-suffix(FEATURE=value, ...)`**: корень, суффикс части речи и необязательные признаки. Корни пока записываются английскими глоссами (`MOVE`, `THINK`), настоящие формы корней ещё не придуманы ([фонология](phonology.md)).

| Суффикс | Часть речи | Пример |
| :-- | :-- | :-- |
| `-o` | имя (предмет, понятие) | `MOVE-o` — движение |
| `-i` | глагол (действие, состояние) | `MOVE-i` — двигаться |
| `-a` | признак (определение) | `MOVE-a` — подвижный |
| `-e` | обстоятельство (образ действия) | `MOVE-e` — подвижно, быстро |

Любой корень берёт любой суффикс. Это даёт семьи слов (*EMOTION*: `-o` emotion, `-i` regret, `-a` emotional, `-e` emotionally) и снимает проблему «слово принадлежит одной части речи». Конверсии типа *work* (`TOOL-o` / `TOOL-i`) естественно ложатся в ту же схему.

Список признаков и корней: [словарь](lexicon.md).

## Пропущенные признаки и «не важно»

**Принято (вариант 2):**

- Признак необязателен. Пропущенный признак имеет **значение по умолчанию** — середину шкалы (`0`). `GO` без признаков — «идти, как обычно».
- Если значение действительно **не важно** (любое подойдёт), это пишется явным маркером `?`: `DOM(SIZE=?)` — дом любого размера.
- Маркер `?` предварительный, обозначение можно сменить.

**Альтернатива (вариант 3, не принят):** признак — интервал на шкале.

- Пропуск = весь диапазон `[-5, +5]` («любое значение»).
- `SIZE=3` — точка, `SIZE=2..4` — интервал (неточность).
- `0` — обычная точка, ничем не особенная.
- Плюсы: снимает вопрос «пропуск или ноль», выражает неопределённость, позволяет убрать часть дублирующих осей (например CERTAINTY/SURENESS).
- Минусы: нужен синтаксис интервалов, сложнее инструменты.

## Примеры

Примеры иллюстративные: корни (`HUM`, `BE-BORN`, …) и признаки (`QUANTITY`, `AGENCY`, …) взяты из исходной ручной гипотезы и не обязаны совпасть с итоговым набором. Суффиксы добавлены по новой схеме. Ошибки оригинала исправлены: в таблице нет признака `VALUE` (есть `COLOR VALUE` и `GOODNESS`), а `QUANTITY=0` — это «many», а не «some».

**All humans are born free and equal.**

```
HUM-o(QUANTITY=5) LI BE-BORN-i(TENSE=-2) LA HUM-o PI AGENCY=5 PI IMPORTANCE=0
```

**Some people fear authority.**

```
HUM-o(QUANTITY=-3) LI FEAR-i(INTENSITY=4) E RULE-o(AGENCY=5)
```

**If someone acts freely, society benefits.**

```
HUM-o(QUANTITY=-3) LI DO-i(AGENCY=5, CERTAINTY=4) LA SOCIAL-LIFE-o LI GROW-i(GOODNESS=4)
```

> Конкретные числа (`QUANTITY=-3`, `IMPORTANCE=0` для «equal») — моя интерпретация, шкалы пока не откалиброваны.
