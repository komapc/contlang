# Синтаксис

## Частицы

Связь слов в предложении задаётся частицами (три из Toki Pona; `PE`, `AND` и связки `FROM`, `FOR`, `LIKE` добавлены). Конструкции вкладываются друг в друга. Сказуемое — слово с формой `| i`, отдельной частицы для него нет: `LI` Toki Pona убран (2026-10-14), его работу делает форма. Признак или имя в роли сказуемого — тот же корень с `| i`: «дом большой» `PLACE INSIDE(=+5) LIVE | o BIG | i`, «собака — животное» `THING(=+4) | i` («быть животным»). Метки времени, отрицания, вопроса стоят на этом глаголе.

| Частица | Роль |
| :-- | :-- |
| `E` | прямое дополнение |
| `FROM` | связка существительных: X сделан из Y |
| `FOR` | связка: X сделан для Y |
| `LIKE` | связка: X похож на Y, но не Y |
| `PI` | связка: всё прочее — X часть Y, находится или живёт в Y |
| `LA` | условие / контекстная клауза |
| `PE` | деятель при страдательном залоге (кем): `… V-4 PE X` |
| `AND` | сочинение «и, также»: между словами, группами и клаузами |

## Слово: смысл | форма

Слово записывается как **`ROOT(=v) ROOT(=v) … | pos метки`**. До `|` стоит смысл: главный корень и до двух корней-модификаторов, у каждого при необходимости значение его оси `(=v)`. После `|`: часть речи и грамматические метки. Корни пока английские глоссы ([фонология](phonology.md)).

| Часть речи | Значение | Пример |
| :-- | :-- | :-- |
| `o` | имя (предмет, понятие) | `MOVE \| o` — движение |
| `i` | глагол (действие, состояние) | `MOVE \| i` — двигаться |
| `a` | признак (определение) | `MOVE \| a` — подвижный |
| `e` | обстоятельство (образ действия) | `MOVE(=+4) \| e` — быстро |

Любой корень берёт любую часть речи (семьи слов, конверсия вроде *work*).

**Роли имени** — после `| o`, одна на слово, не корни и не в лимите (как *-ist, -il, -aĵ, -ec* эсперанто):

| Роль | Значение | Пример |
| :-- | :-- | :-- |
| `agent` | кто или что делает, или человек этой области | `ART(=+5) \| o agent` — художник; `TEXT \| o agent` — писатель; `HAPPEN \| o agent` — причина |
| `tool` | орудие, средство | `TEXT \| o tool` — ручка; `JOIN(=-4) TOUCH(=+4) \| o tool` — нож |
| `result` | что получается | `HAPPEN \| o result` — следствие |
| `quality` | само свойство, состояние | `CAN \| o quality` — способность |

**Метки формы** (не корни, не входят в лимит трёх; пропуск = не указано, как всегда):

| Метка | Значение | Пример |
| :-- | :-- | :-- |
| `T` | время: −5 давно … 0 сейчас … +5 когда-нибудь | `T-2` прошлое, `T+2` будущее |
| `N` | число: 0 нет, +1 один, +2 двое, +3 несколько, мн. ч. … +5 все; на глаголе — число подлежащего: `N+1` ед., `N+2` двойственное, `N+3` мн. (лицо не отмечается) | `N+3` несколько, `N0` ни одного; `MOVE NEAR(=+4) \| i T-2 N+3` — пришли (подлежащее во мн. ч.) |
| `M` | вероятность: −5 точно нет … −3 может быть … +4 наверняка | `M-5` не |
| `A` | вид: −5 вот-вот начнётся … 0 идёт … +5 закончено; `A+5` без `T` — причастие прошедшего (*known, gone*), `A0` — причастие настоящего (*-ing*) | `A-4` начал, `A+5` закончил |
| `C` | сравнение: −3 меньше, +3 больше, +5 самый (больше или меньше того, что назван корнем: `GOOD \| a C+3` лучше, `C-3` хуже) | `BIG \| a C+5` самый большой |
| `I` | интенсивность (насколько сильно проявлен признак или действие): −5 едва … −2 слегка … +2 довольно … +5 чрезвычайно; `I0` не писать (декодер его теряет), для «умеренно» брать `I+1…+2`; не сравнение (для него `C`) | `GOOD(=+3) \| a I+4` очень хороший; `GOOD \| a I-4` едва хороший |
| `K` | побуждение, каузатив (подлежащее воздействует на дополнение `E`, чтобы оно совершило или претерпело действие глагола): −5 помешать, отговорить, запретить … 0 допустить … +5 заставить, вызвать, побудить; без корня действия база — `DO` | `DO \| i K+4 E SOMEONE | o` — заставил его; `CONSUME \| i K+4 E SOMEONE | o` — накормил; `DO \| i K-4 E SOMEONE | o` — помешал ему |
| `D` | определённость: −3 неопределённое (*a*), +3 определённое (*the*) | `PLACE LIVE \| o D+3` — этот дом |
| `R` | событие относительно опорной точки (Рейхенбах: E↔R; `T` задаёт R↔сейчас): −3 раньше опорной точки, 0 одновременно, +3 позже | `T-2 R-3` — уже ушёл (до того); `T-2 R+3` — позже (в прошлом); `T+2 R-3` — к тому времени уйдёт |
| `V` | залог: −4 подлежащее претерпевает (страдательный), 0 происходит само (нет действующего), +4 подлежащее действует намеренно | `PART \| i T-2 V-4` — было разделено; `PART \| i V0` — разделилось само |
| `!` `?` | приказ, вопрос (без значения) | `CONSUME \| i !` — ешь! |

**Опорная точка R** по умолчанию — ближайшее названное время или событие слева (в начале текста — момент речи); явно её задаёт клауза `LA [ … ]` (*после того как…*) или дата в кавычках. `R` не вид: `A` про фазу самого события (начало, процесс, конец), `R` про порядок во времени.

`THING(=+4) BIG(=+5) | o N+3` — слоны (три корня не тратятся на число). `MOVE NEAR(=+4) | i T-2 M-5` — не пришёл. Метки ставятся один раз на главном слове группы.

## Время и отрицание (принято)

Время и отрицание — метки формы `T` и `M` после `|` (таблица выше), а не корни. Пропуск = не указано ([правило нуля](model.md)).

- **`T`** — время от −5 («очень давно») через 0 («сейчас») до +5 («когда-нибудь»): `T-1` только что, `T-3` давно, `T+1` скоро. Без метки время не указано.
- **`M`** — вероятность утверждения: простое утверждение — по умолчанию, метки нет; `M+4` наверняка, `M-1` вероятно, `M-3` может быть (50/50), `M-4` вряд ли, `M-5` точно нет. «Может быть, да» и «может быть, нет» различаются только степенью. Отрицание, «может быть» и «наверняка» — одна метка; отдельной частицы отрицания нет.

Смысловой корень `TIME` слева от `|` (`TIME(=-2) | e` — «вчера», `FEEL(=+4) GOOD(=-4) TIME(=+3) | i` — «бояться») и метка `T` справа не смешиваются. Локальная ось корня пишется `(=v)`: `LIVE(=-2) | i` — «наполовину жив» (спит), `LIVE | i T-2` — «жил».

*She did not see the message* (слух читается через SEE и SAY):

```
SOMEONE | o SEE | i T-2 M-5 E THING | o PI SAY | o
```

Местоимения и указательные слова — коррелятивы из корней ([словарь](lexicon.md)).

## Группа существительного, клаузы и вопросы (принято)

- **Главное слово первым, модификаторы после** (как в Toki Pona). Прилагательные (`-a`) идут сразу за существительным без частицы, плоским списком, и все относятся к нему: `THING | o MOVE | a BIG(=+3) | a` — большая движущаяся вещь.
- **Связки `FROM`, `FOR`, `LIKE`, `PI`** вводят второе существительное, которое сужает главное: `X | o СВЯЗКА Y | o`. Первое слово X — всегда род, вся пара — его частный случай; прилагательные идут перед связкой. Говорящий задаёт вопросы по порядку и берёт первую подходящую связку, слушатель читает каждую одним способом:
  1. `FROM` — X сделан из Y (материал, источник): свеча = `LONG(=0) HEAT(=+5) | o FROM GRAIN(=+5) TOUCH(=-5) | o` («свет из воска»);
  2. `FOR` — X сделан для Y, им пользуются с Y, на Y или Y: ножны = `INSIDE(=+5) JOIN(=+5) | o FOR JOIN(=-4) TOUCH(=+4) | o tool` («покрытие для клинка»);
  3. `LIKE` — X похож на Y, но не Y: подсолнух = `THING(=0) ABOVE(=+5) | o LIKE ABOVE(=+5) HEAT(=+5) | o` («растение, похожее на солнце»);
  4. `PI` — всё прочее: X часть Y или находится, живёт в Y: крыша = `ABOVE(=+5) JOIN(=+5) | o PI PLACE LIVE(=+5) | o`; `SOMEONE | o BIG(=+3) | a PI SOMEONE MANY(=+4) | o` — большой человек народа (правитель).

  Слепой тест ([результат](../data/eval/runs/links/README.md)): одни и те же коды со связками читаются первым словом 46 раз из 80, с одним `PI` вместо всех связок — 31 из 80. Без `LIKE` набор не лучше одного `PI`.
- **`LA`** — условие, контекст и причина («если», «когда», «потому что», «хотя»): `LA [ … ] …`. Клауза с `LA` стоит перед главной, поэтому «поэтому X» передаётся перестановкой: причина идёт в `LA [ … ]`, следствие после неё (`LA [ он болел ] он остался дома`). Если порядок слов приходится менять, его меняют.
- **`AND`** — «и, также»: стоит между сочиняемыми словами, группами и клаузами и связывает то, что слева, с тем, что справа: `LIVE | i AND SAY | i` — *жил и говорил*, `[ … ] AND [ … ]`. В перечислении ставится перед последним элементом. Частица берёт оси как слово: `AND SAME(=-5)` — но, `AND SAME(=-2)` — хотя, `AND HAPPEN(=+4)` — поэтому, `AND HAPPEN(=-4)` — потому что, `AND BIG(=+4)` — тем более, `AND | M-3` — или (метка вероятности, не корень); порядок слов исходный ([encoding](encoding.md)). Отдельная частица, поэтому `JOIN`, `CHANGE`, `SAME` как связки не писать (они означают присоединение, изменение, тождество).
- **`;`** — граница независимых клауз длинного предложения: каждая клауза со своими словами и частицами (`SOMEONE | o SAY | i T-2 ; THING | o LIVE | i`). Скобки `[ … ]` только для вложенной клаузы или клаузы-дополнения. Каждое слово, в том числе главное существительное перед связкой (`PI`, `FROM`, `FOR`, `LIKE`) и `E`, имеет свою форму `| …` (хотя бы часть речи); слова не склеиваются без `|`. Проверка — `scripts/mincode/validator.py` (ввод `;` — по результату валидатора: кодировщики сами писали его в 25 из 60 предложений).
- **`{ … }`** — явная граница слова в записи предложения: каждое слово `{ ROOTS | FORM }` в своих фигурных скобках (до трёх корней, одна форма); вне скобок только частицы `E PI FROM FOR LIKE LA PE AND`, `[ ]`, `;` и имена в кавычках (`"Europe"`). Без скобок кодировщики не ставили `| форма` у каждого слова (ошибки валидатора у 73–88% кодов; со скобками 28–70%, смысл по слепому судье на настроечном наборе +0,12 [+0,01, +0,25], на отложенном +0,01 [−0,20, +0,23], то есть смысл не улучшает и не ухудшает; [результат](../data/translation_test/clause_rule.md)). Пример: `{ SOMEONE | o } { SAY | i T-2 } E { THING | o }`; модификатор после `AND` может быть без формы: `AND { SAME(=-5) }`. Запись отдельного слова (`THING(=+4) BIG(=+5) | o N+3`) скобок не требует.
- **Клауза-содержание** (после *думать, сказать, знать, хотеть*) берётся в скобки как дополнение: `THINK | i E [ … ]`. Устный маркер скобок — вопрос для фонологии.
- **Вопрос** — запрошенное значение `?`: да/нет — метка `?` на сказуемом, «кто/что» — `SOMEONE | o ?`, `THING | o ?`. Отдельного слова вопроса нет.
- **Даты и время по часам** — в кавычках, как числа: `"5.3"`, `"3:00"`; единицы времени и части суток — рецептами ([encoding](encoding.md), «Время»).

*Who said that the king is dead?*

```
SOMEONE | o ? SAY | i T-2 E [ SOMEONE RULE(=+5) SEX(=+5) | o D+3 LIVE(=-5) | i ]
```

## Пропущенные значения и «не важно»

Действует [правило нуля](model.md): ось не написана — значение не указано (ничего не стоит по битам); `(=0)` — явная середина оси. `MOVE | i` — «двигаться» без уточнения скорости, `MOVE(=0) | i` — «идти обычным шагом».

- Если значение действительно **не важно**, ось просто не пишется. Отдельный маркер `?` нужен только для запроса («какое значение?»).
- Прежнее решение «пропуск = середина шкалы» и вариант «признак — интервал `[-5, +5]`» сняты: первое противоречит правилу нуля, второе не понадобилось.

## Примеры

Проверены валидатором (`scripts/mincode/validator.py`); слепым тестом не проверялись.

*All humans are born free and equal.*

```
SOMEONE MANY(=+5) | o LIVE BEGIN(=-5) | i T-2 V-4 CAN(=+5) | a SAME(=+5) | a
```

*Some people fear authority.*

```
SOMEONE MANY(=0) | o N+3 FEEL(=+4) GOOD(=-4) TIME(=+3) | i E RULE(=+4) | o
```

*If someone acts freely, society benefits.*

```
LA [ SOMEONE | o DO | i CAN(=+5) | e ] SOMEONE PART(=+5) | o CHANGE GOOD(=+3) | i
```
