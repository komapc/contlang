# Философия min-co

**min-co** (*minimal + continuous*) — минимальный философский язык (artlang) для точной и гибкой мысли.

- Минимум грамматики и словаря (вдохновлено Toki Pona и эсперанто).
- Максимум выразительности через небольшой набор универсальных непрерывных признаков.
- Понятия — не категории, а позиции в концептуальном пространстве.
- Нюанс вместо ярлыка: смысл слова — корень плюс непрерывные поправки.

## Принципы

1. **Малый набор общих корней.** Около 30 общих, не привязанных к части речи понятий (*move, think, emotion, amount, …*). Корни выбираются из данных так, чтобы покрывать словарь (см. [словарь](lexicon.md)).
2. **Часть речи — суффикс эсперанто.** `-o` имя, `-i` глагол, `-a` признак, `-e` обстоятельство. Любой корень берёт любой суффикс: `MOVE-o` (движение), `MOVE-i` (двигаться), `MOVE-a` (подвижный), `MOVE-e` (подвижно). Форма отделена от смысла: корень не знает, какой он части речи.
3. **Универсальные непрерывные признаки.** Смысловые поправки слова — несколько общих осей (порядка 6–9), одинаковых для всех корней, значения от -5 до +5. Локальных осей у отдельных корней нет: язык не должен разрастаться до сотен шкал. Корень при желании использует лишь часть осей (применимость), остальные не указываются.
4. **Признаки необязательны.** Пропущенный признак принимает значение по умолчанию (середина шкалы, `0`). Если значение не важно, это отмечается маркером `?` (см. [синтаксис](syntax.md)).
5. **Минимальная грамматика.** Связь слов в предложении — частицы из Toki Pona (`LI`, `E`, `PI`, `LA`). Их соотношение с суффиксами остаётся открытым вопросом ([план](roadmap.md)).
6. **Бесконечный словарь.** Слова порождаются как корень + суффикс + признаки. Фиксированный словарь не нужен.

## Откуда это взялось

Схема не придумана целиком вручную, а подобрана экспериментами на данных (английский, эмбеддинги ConceptNet Numberbatch, 3000 слов): сравнивались глобальные оси, корни с локальными осями, корни с универсальными осями, непрерывная форма против суффикса.
