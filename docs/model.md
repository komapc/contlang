# Модель: корень и структура

Всё в языке сводится к двум вещам: корню и структуре. Ось — не отдельная сущность, а корень в позиции модификатора со значением (как в эсперанто корень и суффикс — примерно одно и то же). Решено в обсуждении; прежняя модель «корень, ось, структура» заменена.

## 1. Корень

Дискретная опора: что это за предмет, действие, понятие. Около 36, в основном примитивы NSM (*someone, thing, move, think, want, hear, place, …*); текущий список — в [словаре](lexicon.md). Корень не знает части речи.

**У каждого корня своя ось или никакой.** Ось — непрерывная шкала от −5 до +5, по умолчанию 0, заданная полюсами в духе NSM: у GOOD «плохо … хорошо», у INSIDE «снаружи … внутри», у LIVE «мёртвое … живое». Значение относительно корня (*big mouse* меньше, чем *small elephant*). Оси бывают **двусторонние** (полюса, −5 … +5: GOOD, BIG, INSIDE) и **односторонние** (степень от нуля, 0 … +5: MANY — ни одного … все).

**Правило нуля.** Ось не написана — значение не указано, это ничего не стоит по битам. `(=0)` — явное значение: середина у двусторонней оси, настоящий ноль у односторонней. Точные количества (`1`, `17`) — числа из послаблений.

Общих «универсальных осей» (M1–M9) нет: если нужен тонкий оттенок, берётся ещё один корень.

## 2. Составные слова

Слово — один, два или три корня, как в эсперанто. Главное слово первым, каждое следующее уточняет всё, что стоит перед ним, без скобок (слева направо); больше трёх корней нельзя. Второй корень работает то как корень, то как суффикс. Корень в позиции модификатора с значением оси — это «ось» прежней модели:

| слово | запись |
| :-- | :-- |
| дом | `PLACE-o LIVE-i` |
| спальня | `PLACE-o LIVE-i(=-2)` |
| морг | `PLACE-o LIVE-i(=-5)` |
| хорошая вещь | `THING-o GOOD-a(=+3)` |

Ось без вещи (*good*) — корень в позиции главного слова: `GOOD(=+5)`. Двусмысленная группировка пишется скобками `[ … ]`.

Цена по битам: плотно (9 общих осей) ≈ 31 бит на значения; разреженно (оси в корнях) ≈ 8,4 бита на каждую нужную ось (номер корня + значение). Разреженный способ дешевле, пока слову нужно не больше трёх-четырёх осей. Проверка на данных ещё не сделана.

## 3. Структура

- **Суффикс части речи:** `-o` имя, `-i` глагол, `-a` признак, `-e` обстоятельство (эсперанто). Принято: 2 бита, улучшал метрики.
- **Порядок:** главное слово первым, определения после.
- **Частицы:** `E` дополнение, `PI` существительное-определение, `LA` условие, скобки `[ … ]` для клаузы, `?` для запрошенного значения. `LI` (сказуемое) частично дублирует суффикс `-i`: предлагается убрать, пока не решено.
- **Признаки глагола** `TIME` и `MAYBE` — те же корни со своими осями в позиции признака сказуемого.

## Что взять у других языков (принято к проработке)

- Таблица коррелятивов эсперанто: вопросы, указания, «все / никто» собираются из корней SOMEONE, THING, PLACE, TIME, NEAR, MANY и частицы `?` (см. словарь).
- Свидетельность («видел», «слышал») — корни SEE, THINK, KNOW (HEAR убран) как частица-определение предложения.
- Число — корень MANY (`THING MANY(=+3)` — «несколько»); ноль — число не указано.
- Места аргументов у корня (Ложбан) вместо падежей.
- Длина формы по частоте (код Хаффмана).
- Маркер имён и заимствований (Ложбан, *cmevla*) для послаблений.
- Формальная грамматика, проверяемая парсером.

## Что осталось открытым

- Абстракции (*responsibility, category, probability, career…*) пока без корней; корни добавляются по мере провалов.
- Проверить на данных: разреженное кодирование (корень + до 3 корней-модификаторов) против 9 общих осей при одинаковом числе бит.
- Убирать ли `LI`.
- Глаголы изменения через ось (*improve* = `HAPPEN-i(GOOD=+3)`), если идея понравится.
