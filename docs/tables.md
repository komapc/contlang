## Форма слова: после `|`

Часть речи (2 бита): `o` имя, `i` глагол, `a` признак, `e` обстоятельство.

Метки (не корни, в лимит трёх корней не входят; метки ставятся один раз на главном слове группы):

| метка | что | шкала |
| :-- | :-- | :-- |
| `T` | время: опорная точка относительно «сейчас» | −5 давно … 0 сейчас … +5 когда-нибудь (`T-2` прошлое, `T+2` будущее) |
| `R` | время события относительно опорной точки | −3 раньше … 0 одновременно … +3 позже |
| `N` | число | 0 нет … +5 все (`N+3` несколько) |
| `M` | отрицание, вероятность | −5 не … −3 может быть … +4 наверняка |
| `A` | вид | −5 вот-вот начнётся … 0 идёт … +5 закончено |
| `C` | сравнение | −3 меньше, +3 больше, +5 самый |
| `I` | интенсивность | −5 едва … −2 слегка … +2 довольно … +5 чрезвычайно (`I+4` очень; `I0` не писать) |
| `D` | определённость | −3 *a*, +3 *the* |
| `V` | залог | −4 претерпевает, 0 само собой, +4 намеренно |
| `K` | побуждение (каузатив) | −5 помешать, отговорить … 0 допустить … +5 заставить, вызвать |
| `!` | приказ | без значения |
| `?` | вопрос | без значения |

## Частицы фразы

| частица | роль |
| :-- | :-- |
| `E` | дополнение |
| `PI` | существительное-определение |
| `LA` | условие, контекст, опорная точка для `R` |
| `PE` | деятель при `V-4` («кем») |
| `AND` | сочинение: и, также |
| `LI` | сказуемое (решено: остаётся отдельным словом) |
| `[ ]` | клауза |
| `"…"` | имена, числа, даты, латынь |

## Счёт

Корней 46 (39 с осью, 7 без); меток формы 12; частиц 7 (+ кавычки); частей речи 4. Лимит: до 3 смысловых корней в слове; `ABSTRACT` как индикатор абстрактности (абстрактные существительные) сверх лимита, четвёртым.
