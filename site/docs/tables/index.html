Корни с осью (39)

Ось — шкала −5 … +5; ось не написана — значение не указано, (=0) — явная середина.

корень −5 0 +5
GOOD плохо хорошо
BIG мало много
NEAR далеко, за границей, в пути близко, рядом, в центре (этот / тот)
ABOVE ниже выше
LIVE мёртвое живое
SAME другое, особое то же, общее
TIME давно сейчас когда-нибудь
INSIDE снаружи на границе внутри
PART крошка (−2 часть, член) +2 целое, «полностью» +5 группа, набор (после слова: собрание таких вещей, -aro)
SIDE зад, назад; вернуться перёд, вперёд; предстоящий
KNOW глупо, нелепо, не знаю осведомлён знаю, сообщить, научить
WANT ненависть любовь
HEAT лёд тепло огонь
BEGIN начать идёт закончить
GIVE схватить, отнять обмен, получить отдать, подарить, пожертвовать
TOUCH мягкое, гладкое, нежное обычное твёрдое, жёсткое, суровое
SEX женское мужское
THINK сомневаться думать решить
CAN невозможно (−3 трудно) легко
MANY −5 ни одного, нет вовсе (−3 почти нет, нехватка) 0 сколько-то +5 все (+3 многие)
SOMEONE они / другой кто-то я (+3 ты)
THING камень растение животное (+4)
MOVE стоять идти мчаться
FEEL вялость сильное чувство
RULE личное, неформальное обычное официальное, учреждение, закон
CHANGE остаться меняться превратить, измениться полностью
ART расчёт, техника, точные науки смешанное творчество, культура, гуманитарное
JOIN отделить, убрать состав не меняется присоединить, добавить, объединить
VALUE дёшево, распродажа, купля-продажа обычная цена дорого, ценно, важно
CARE небрежно, ошибка, вина обычно старательно, тщательно
FRIEND враг, враждебно нейтрально друг, дружелюбно, добрый
MOOD горе, отчаяние, трагическое (−3 грусть) всерьёз, спокойно смешно, хохот (+3 весело, радостно)
CONSUME выделить (писать, говорить, испражняться) обмен поглотить (есть, читать, слушать)
MEASURE величина сама по себе (размер, количество) уровень, степень величина относительно другой (отношение, доля, процент, статистика)
LONG нить, ткань, верёвка (тонкое, гибкое) проволока, прут, крепёж балка, доска, бревно, деревянная мебель
SAY шёпот, бормотание обычная речь крик, рёв
GRAIN газ, пар (−3 жидкость, вода) сыпучее, рассыпчатое цельное, одним куском
FIGHT игра, спорт, соревнование драка, спор война насмерть
LAND море, вода берег суша, твёрдая земля

Корни без оси (6)

корень значение
HAPPEN событие, случаться
BODY тело
SEE видеть
DO делать
PLACE место
TEXT письменная речь, текст, запись

Форма слова: после |

Часть речи (2 бита): o имя, i глагол, a признак, e обстоятельство.

Метки (не корни, в лимит трёх корней не входят; метки ставятся один раз на главном слове группы):

метка что шкала
T время: опорная точка относительно «сейчас» −5 давно … 0 сейчас … +5 когда-нибудь (T-2 прошлое, T+2 будущее)
R время события относительно опорной точки −3 раньше … 0 одновременно … +3 позже
N число 0 нет … +5 все (N+3 несколько)
M отрицание, вероятность −5 не … −3 может быть … +4 наверняка
A вид −5 вот-вот начнётся … 0 идёт … +5 закончено
C сравнение −3 меньше, +3 больше, +5 самый
I интенсивность −5 едва … −2 слегка … +2 довольно … +5 чрезвычайно (I+4 очень; I0 не писать)
D определённость −3 a, +3 the
V залог −4 претерпевает, 0 само собой, +4 намеренно
K побуждение (каузатив) −5 помешать, отговорить … 0 допустить … +5 заставить, вызвать
! приказ без значения
? вопрос без значения

Роли имени

После | o, не больше одной, без значения; в лимит корней не входят.

роль что значит
agent тот, кто это делает, или человек этой области (человек или вещь): TEXT | o agent писатель, HAPPEN | o agent причина, ART(=+5) | o agent художник
tool орудие, средство: TEXT | o tool ручка, JOIN(=-4) TOUCH(=+4) | o tool нож
result то, что получается: HAPPEN | o result следствие
quality само качество или состояние: GOOD | o quality доброта, CAN | o quality способность

Частицы фразы

частица роль
E дополнение
FROM связка существительных: X FROM Y — X сделан из Y (материал, источник); первым проверяется он
FOR связка: X FOR Y — X сделан для Y (им пользуются с Y, на Y или Y); вторым
LIKE связка: X LIKE Y — X похож на Y, но не Y; третьим
PI связка: X PI Y — всё прочее: X часть Y или находится, живёт в Y; последним
LA условие, контекст, опорная точка для R
PE деятель при V-4 («кем»)
AND сочинение: и, также
[ ] клауза
; граница независимых клауз длинного предложения (у каждого слова своя форма | …)
"…" имена, числа, даты, латынь

Счёт

Корней 45 (39 с осью, 6 без); меток формы 12; ролей имени 4; частиц и знаков 11 (+ кавычки); частей речи 4. Лимит: до 3 корней в слове, без исключений.
