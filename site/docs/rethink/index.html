Пересмотр языка: где мы и что менять (2026-10)

Обновление (2026-10-14): мера «близко»

Главная мера теперь другая: доля первых ответов слепого читателя, которые слепой судья (Haiku) считает «близко» — то же смысловое поле (2 близко, 1 рядом, 0 мимо). Место среди 10 721 слова ниже — прежняя мера, оставлена для истории.

  • 1000 слов (big1000): кодер сайта 24 %, Haiku с ENC_SPEC 52 %.
  • Приняты (решение пользователя 2026-10-14, без слепого теста): кодер сайта всегда кодирует базовую форму и дописывает метки (discussed → код discuss + T-2, -ing → A0, причастие-признак → | a V-4, множественное → N+3, степени → C+3/C+5); базы вне словаря берутся из Numberbatch; у омонима кодируется один смысл (WordNet, при почти равной частоте — ближайший к вектору слова). scripts/site/build_words.py → infl, extra, sense. Поправки 2026-10-14: часть речи словоформы — по Brown, если форма там ≥ 5 раз и Brown видит имя или признак (attacks, plans, projects, tears → имя, surprising → признак; 157 форм); якоря смысла — без гиперонимов (обратное чтение: слово первым 29,9 → 32,1 %).
  • Приняты: оси 8 корней (LONG, KNOW, MEASURE, TOUCH, NEAR, GIVE, VALUE, CARE) по словам вокруг выученных атомов и роль agent у людей (fix1).
  • Слепые тесты кодера (не приняты): выбор кода моделью читателя (reader2, +4,7 % [−4,0 … +13,3]), экономный кодер — меньше корней, без нулей (occam, −1,3 % [−8,0 … +5,3]).
  • Не приняты: раздельные коды смыслов многозначных слов (senses, −2 %), корень KIND (kind, +5,6 % при пороге; только головой +6,7 % [−2,7 … +16], side_kind; решение пользователя 2026-10-14), роли tool и quality по WordNet.
  • Отложено: убрать у кодера сайта пару через PI.

Мера и эталон (прежняя)

Точность чтения измеряется местом загаданного слова среди 10 721 слова словаря сайта: слова упорядочены по cos с ответом слепого читателя, 1 — ответ ближе всего к загаданному. Берётся среднее геометрическое мест по 200 прочтениям: 100 слов dev, по два читателя Haiku. Подробности — data/eval/runs/toki.

Мера для «в 10 раз точнее». Место с синонимами: попаданием считается любое слово из синсетов WordNet загаданного слова в его части речи (car вместо automobile — место 1). Среднее геометрическое такого места — это сколько равновероятных кандидатов остаётся у читателя; log2 места — оставшаяся неопределённость в битах. «В 10 раз точнее» = в 10 раз меньше кандидатов = на 3,3 бита меньше.

Токипона 120 62 5,9 0,68 142
min-co 51 25 4,7 0,58 121

математика сайта 137 82 6,4 0,71 156
  • Сейчас min-co в 2,5 раза точнее Токипоны (на 1,2 бита). Цель 10× — место с синонимами около 6.
  • Почему не другие меры:
  • 1 − cos сжата сверху и снизу: в 10 раз меньшая ошибка — это cos 0,93, почти только точные слова; разница Токипоны и min-co на ней 0,68 против 0,58.
  • доля промахов (вне первых 10 с синонимами): 142 против 121 из 200 — почти не различает языки, а 10× (14 промахов из 200) означало бы почти безошибочное чтение.
  • место без синонимов штрафует за car вместо automobile: синонимы делят одно место, читатель не виноват.

Предложения

# предложение основание что убирает статус
1 Короткая спецификация v2 (spec_v2.md, 4,8 КБ вместо 11 КБ) Слепой тест на тех же 100 словах: v2 / v1 = 1,19 (95 %: 0,76–1,87), разницы нет Четвёртый корень ABSTRACT, исключение для сторон света, BIG как «степень», старая запись -o, три разных описания меток. Одно правило осей: −5 противоположный полюс, 0 середина, +5 полный полюс принято (2026-10)
2 Роли в форме вместо осей DO и HAPPEN: agent, tool, result, quality после | o (как -ist, -il, -aĵ, -ec в эсперанто) Входят в v2. Кодировщик ставил их в 10 словах из 100: telegraph 18 → 2, но beef 1 → 114 (result не к месту) Две оси, которые не шкалы (деятель … действие … орудие; причина … следствие) принято с v2; с 2026-10 кодер сайта ставит agent людям (noun.person в WordNet): +19 % «близко» [+10 … +30], fix1
3 Список частых слов с закреплёнными кодами (около 1000, по проверенным рецептам). Состав — для остального Лучший из трёх ответов уже на месте 21: нужное слово обычно среди вариантов, но первым не выходит. Закреплённое слово читается точно (рецепты сайта) — единственный рычаг к 10×, который я вижу; меняет принцип «фиксированного словаря нет»; на этих 100 словах не проверено (сколько из них попадёт в список — не считалось)
4 Мерить на предложениях, а не на словах toki_sents: те же 100 слов в предложениях. Токипона 62 → 26, min-co 28 → 40. Токипона / min-co = 0,65 (0,36–1,17), разницы нет. Контекст помогает многозначной Токипоне. min-co в предложении кодирует слово грубее, а читатель не достраивает код по смыслу — сделано: выигрыш min-co на словах в тексте пропал
5 Кодер сайта: выбирать корни, которые ставят модели (приор по корпусу кодов моделей, kNN), а не только y ≈ x Математика 137 против 51 у модели; подгонка словаря не сдвинула ② (anchor) — проверено: перенос кодов модели в словарь (distill) читается почти как прежде, не принято
6 CARE — отношение к делу, TONE заменён на FRIEND (враг … друг) Для математики корни разошлись: cos центров 0,65 → 0,12 (выученный словарь 0,07). Слепой тест на 20 словах (friend): FRIEND / TONE 1,45 (0,71–3,01), разницы нет; friend лучше, polite хуже Два корня с близкими центрами принято (2026-10)
7 Редкие корни не убирать: NEAR, WANT, BEGIN, SEX, FEEL, CHANGE, MEASURE (4–8 раз на 458 кодов) Каждый несёт свои слова (king, improve, unit…) — оставить
8 Метки I, C, N на словах почти не встречаются (2, 1, 1 раз) На словах их не проверить — решать после теста на предложениях
9 Одно правило кавычек: имена собственные, цифры, научные названия видов и веществ Входит в v2 Списки категорий в encoding.md принято с v2
10 Глагол с головным корнем со значением = переход в это состояние (BIG(=+3) | i grow, LIVE(=-5) | i K+3 kill), без CHANGE verbs: 40 глаголов, B / A = 0,89 (0,67–1,19), разницы нет. Лучше learn, forget, хуже weaken, accelerate CHANGE в глаголах смены состояния не принято: разницы нет
11 Новые корни по худшим словам: свет (тёмный … яркий), сила (слабый … сильный), влажность (сухой … мокрый), открытость, полнота; одежда, помощь, электричество, слово/имя Глаголы darken, brighten, weaken, strengthen, dry, open, close, fill, empty плохи в обоих вариантах (место 50–1800): у смысла нет оси. Слова теста Токипоны suit, assistant, current, note, sentence — кандидаты: нужны кластеры и слепой тест
