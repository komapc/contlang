# min-co: кодировать и раскодировать слово

Источник правды — текущий список корней и осей в `docs/lexicon.md` (раздел «Корни: текущий список») и правила в `docs/model.md`. **Перед работой прочитай оба раздела**: список меняется (корни и оси добавляются), копия ниже может устареть.

## Как читается код

- Слово = **главный корень + суффикс**, затем **модификаторы** слева направо; каждый следующий уточняет всё, что стоит до него. Не больше трёх корней в слове (наше правило, не ограничение языка: больше — это уже фраза).
- Суффикс части речи один на корень: `-o` предмет/имя, `-i` действие, `-a` признак, `-e` обстоятельство.
- Модификатор — либо `КОРЕНЬ(=v)` (только значение на собственной оси корня, v от −5 до +5), либо полный корень со своим суффиксом (`LIVE-i`, `PI SAY-o`).
- Ось не написана — значение не указано; `(=0)` — явная середина (у односторонней оси MANY — ноль).
- Дополнение — `E X`; существительное-определение — `PI X`; вопрос — `?`; скобки `[ … ]` для клаузы.
- Числа, имена, страны, религии, латинские и химические названия идут как есть, в кавычках (`"Christ"`, `"17"`).

## Кодирование (английское слово → код)

1. Определи значение. Если слово многозначное и пользователь его не указал, возьми самое частое (первое в WordNet), **назови выбранное значение одной строкой** и предложи другие коды для остальных значений.
2. Выбери главный корень: ближайший по смыслу из списка; по части речи слова — суффикс.
3. Сначала используй оси самого главного корня (например, `GOOD-a(=-5)` — *worst*), потом добавляй второй и третий корень.
4. Приёмы, проверенные слепыми тестами (`data/translation_test/roundtrip_30.md`):
   - действия без своего корня — через `DO-i E …` (делать, вызывать) или `SAY-i …` (говорить, просить);
   - «против» (*protest, refuse*) — через явного носителя: `SOMEONE-o MANY(=+4) SAY-i WANT(=-5)`; голое `WANT(=-5)` декодер часто игнорирует;
   - «мочь, трудно, возможно» — `CAN` (`DO-a CAN(=-3)` — *difficult*); не используй `MAYBE` вместо `CAN`;
   - причина и следствие — ось `HAPPEN` (`HAPPEN-o(=-4)` причина, `HAPPEN-o(=+4)` следствие, `HAPPEN-e(=-4)` потому что);
   - решение — ось `THINK` (`THINK-i(=+5)` решить, `THINK-i(=-4)` сомневаться);
   - количество — `MANY` (ноль — ни одного, +5 — все), точные числа цифрами;
   - не клади `TIME` на ось, если нужно «потом»: `TIME(=+1)` декодируется как *soon*;
   - `ABOVE`, `INSIDE`, `BIG` — только настоящие «верх / внутри / размер»; метафора (*roof*, *coffee*, *desk*) и усилитель (`BIG(=+5)` как «очень») в слепом тесте на 200 слов почти всегда читались неверно (data/translation_test/roundtrip_200.md);
   - еда и питьё — `CONSUME`, ёмкость — `CONTAINER`; корней HEAR, KIND, WORD, PEOPLE больше нет (PEOPLE = `SOMEONE-o MANY(=+4)`); новые оси: HEAT (холодно … жарко), BEGIN (начало … конец), GIVE (взять … отдать);
   - местоимения — ось `SOMEONE` (я +5, ты +3, он −3), множественное через `MANY`: `SOMEONE-o(=+5) MANY(=+3)` — *we*; одушевлённость — ось `THING` (камень −5, растение 0, животное +4); скорость — `MOVE`, возбуждение — `FEEL` (приятно или нет — `GOOD`); закон и власть — `RULE`, бой и война — `FIGHT` (*peace* = `FIGHT-o MANY(=0)`);
   - эмоции: `FEEL` (возбуждение) + `GOOD` (приятность) + корень по смыслу: страх `TIME(+3)` (плохое впереди), злость `FIGHT-a`, социальные `SOMEONE-o` (+ `SEE-i`); оси `NEAR`/`WANT` для направления не работают;
   - не злоупотребляй `ABOVE` для «важного»: *elect* через `ABOVE(=+4)` читается как *worship*.
5. Ответ: код, одна строка «как читается», уверенность (высокая / средняя / низкая) и 1–2 слова, с которыми его могут спутать.
6. Если пользователь просит проверку: запусти субагента, дай ему **только** спецификацию (разделы «Как читается код» и список корней и осей) и код, без оригинала, и сравни ответ. Оценки: точно / синоним / рядом / мимо.

## Раскодирование (код → английское слово)

1. Разбери код: главный корень и суффикс, модификаторы по порядку, значения осей.
2. Для каждого модификатора скажи, что он уточняет; значения читай по шкалам осей из `docs/lexicon.md`.
3. Дай **одно лучшее слово и две альтернативы**, с краткой причиной. Если код допускает несколько частей речи или значений, так и скажи.
4. Не выдумывай корней, которых нет в списке; неизвестный корень — признак ошибки в коде, сообщи об этом.

## Ограничения

- Список корней и осей — рабочий черновик; новые корни вводятся по правилу: кластер из десятка частых слов и два неудачных слепых теста с имеющимися корнями и осями (сначала пробуется ось у существующего корня).
- Кодирование неоднозначно по природе: разные слова могут получить близкие коды. Уверенность называй честно.
