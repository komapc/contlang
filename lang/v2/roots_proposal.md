# Предложение: новые корни для v2b (черновик, решает пользователь)

Основание — [words1](../../data/eval/runs/words1/README.md): смысл теряется в коде, а не при чтении; Toki Pona сохраняет
повседневные конкретные слова, которых нет среди 45 корней v1. Чтобы не подгонять под 60 dev-предложений, кандидаты взяты не
из потерянных слов, а из **словаря Toki Pona (pu, 120 слов): какие его понятия v1 не покрывает ни корнем, ни значением оси**.
Проверка решения — на hold-части bench1 (не тронута).

## Что Toki Pona называет, а v1 нет

| группа | слова Toki Pona | в v1 |
|---|---|---|
| цвет | *kule, loje, jelo, laso, walo, pimeja* | нет |
| свет | *suno* (солнце, свет), *walo / pimeja* | нет (`HEAT(=+5)` — огонь, не свет) |
| части тела | *lawa, luka, noka, uta, kute, lukin, sinpin, selo, nena* | только `BODY` без оси |
| родство | *mama* | нет |
| форма | *sike* (круг, шар), *supa* (плоскость, стол, кровать), *lipu* (плоская вещь), *nena* (бугор) | только `LONG` (длинные вещи) |
| вместилище, проём | *poki* (коробка, сумка, чашка), *lupa* (дыра, дверь, окно) | нет |
| сила | *wawa* | нет |
| правда, бытие | *lon* (есть, находится, правда) | нет (корень TRUE обсуждался для v1 и заморожен) |
| животные по видам | *kala, waso, pipi, soweli, akesi* | `THING(=+4)` + место (`LAND(=-5)` — морское) — покрывается рецептом |
| вкус, грязь | *suwi, jaki* | нет; редко |

## Кандидаты (каждый — с осью, как остальные корни)

Частота — слова группы в корпусе Brown на миллион слов (многозначные *back, close, light, real* её завышают; для сравнения:
существующие корни MOOD — 278, CARE — 128).

| корень | ось | частота |
|---|---|---|
| `BODY` (ось вместо «без оси», новой единицы нет) | −5 ступня, нога … −2 живот, бёдра … 0 туловище, грудь … +3 шея … +4 лицо, рот, глаза … +5 голова | 2684 |
| `KIN` родство | −5 потомок … −3 ребёнок, сын, дочь … 0 брат, сестра, супруг, родня … +3 родитель, мать, отец … +5 предок | 1818 |
| `TRUE` правда | −5 ложь, выдумка … 0 возможно, кажется … +5 правда, на самом деле, существует | 1408 |
| `OPEN` открытость | −5 закрытое вместилище: коробка, сумка, чашка … 0 крышка, покров … +5 проём, дыра, дверь, окно, открытый | 1321 |
| `LIGHT` свет | −5 чёрный, тьма … 0 серый, сумрак … +5 белый, яркий, свет, сияние (солнце — `LIGHT(=+5) ABOVE(=+5) THING`) | 1199 |
| `STRONG` сила | −5 слабый, хрупкий … 0 обычный … +5 сильный, мощный, сила | 1057 |
| `SHAPE` форма | −5 круглое, шар, круг, кольцо … 0 брусок, куб … +5 плоское: лист, доска, стол, пол, кровать (вытянутое — `LONG`) | 1019 |
| `HAND` рука | −5 палец … 0 кисть, рука … +5 вся рука, плечо (также: держать, ручной) | 896 |
| `COLOR` цвет | −5 красный … −3 оранжевый … −1 жёлтый … +1 зелёный … +3 синий … +5 фиолетовый (спектр; светлое и тёмное — `LIGHT`) | 856 |

Цена по правилу подсчёта [retell1](../../data/eval/runs/retell1/dec.md): 8 новых корней, ось у `BODY` — 76 → **84** единицы
(Toki Pona — 120). Части лица (глаз, рот, ухо) остаются рецептами: глаз `BODY(=+4) SEE`, рот `BODY(=+4) CONSUME`, ухо
`BODY(=+4) CONSUME SAY`.

Отдельно (не входит в 84): исправления осей из пилота — `SAME` −4 «особый», `CHANGE`, `RULE`; перед этим посчитать, как часто
они встречаются в кодах dev, — если редко, отдельное плечо не окупится.

## Как проверить

Вариант **v2b = v1 + выбранные корни** (`lang/v2b/`), кодировщик с инструкцией base1, тот же протокол, что в retell1:
v2b против перечитанных mc и tp на dev; если прирост есть — подтвердить на hold.
